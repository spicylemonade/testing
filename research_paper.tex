% ABSTRACT

\begin{abstract}
Voxel grid traversal is a fundamental operation in ray tracing, volumetric rendering, medical imaging, and robotics, yet existing algorithms adopt a single fixed strategy regardless of local grid characteristics.
We present \textbf{Adaptive Hybrid Traversal (AHT)}, a novel algorithm that combines hierarchical empty-space skipping, branchless DDA stepping, and per-brick density-adaptive strategy selection into a unified traversal framework.
AHT partitions the voxel grid into $8^3$ bricks, precomputes per-brick occupancy metadata, and at traversal time dynamically selects between block skipping, sparse early-termination, and full branchless DDA based on local density.
We implement and benchmark seven traversal algorithms---including the classic Amanatides--Woo DDA~\cite{amanatides1987fast}, 3D Bresenham~\cite{bresenham1965algorithm}, branchless DDA, Morton-coded cache-aware DDA, SIMD-vectorized batch DDA, hierarchical DDA, and the proposed AHT---across 441 benchmark configurations spanning grid sizes from $32^3$ to $256^3$, three occupancy densities, and three ray distributions.
On structured sparse grids, AHT achieves $2.1$--$4.7\times$ speedup over flat DDA; combined with coherent ray batching, throughput improvements reach $10\times$.
AHT is never more than $0.7\times$ slower on dense grids, providing robust performance across heterogeneous scenes.
All implementations, benchmarks, and 180 correctness tests (98\% code coverage) are publicly available.
\end{abstract}

\section{Introduction}
\label{sec:intro}

Traversing a ray through a regular three-dimensional voxel grid---enumerating every occupied cell the ray intersects---is a core primitive in computer graphics~\cite{amanatides1987fast}, medical image reconstruction~\cite{siddon1985fast}, autonomous navigation, and scientific visualization.
The seminal Digital Differential Analyzer (DDA) of Amanatides and Woo~\cite{amanatides1987fast} remains the most widely used algorithm, requiring only two floating-point comparisons and one addition per step.
Despite decades of optimization---including Bresenham-style integer variants~\cite{bresenham1965algorithm,liu2004integer}, supercover extensions~\cite{cleary1988analysis}, GPU-accelerated traversals~\cite{es2007accelerated}, sparse voxel octrees~\cite{laine2010efficient}, and bitmask-based hierarchical skipping~\cite{dubiousconst2024sparse64}---a significant gap persists: all existing methods apply a single, fixed traversal strategy to the entire grid.

Real-world voxel grids are \emph{heterogeneous}.
Medical CT volumes contain dense tissue surrounded by empty air.
Voxel game worlds feature detailed surfaces enclosing vast empty interiors.
Architectural scenes have sparse exterior regions and densely furnished rooms.
A flat DDA wastes computation traversing empty space; a hierarchical method pays dispatch overhead in dense regions where there is nothing to skip.

\paragraph{Gap in the literature.}
Prior hierarchical approaches~\cite{laine2010efficient,dubiousconst2024sparse64,kampe2013high} use uniform two-level or multi-level traversal without adapting strategy to local density.
Cache-aware layouts~\cite{morton1966computer,lefebvre2006perfect} improve memory access patterns but do not reduce computational steps.
SIMD and GPU parallelism~\cite{es2007accelerated,friederichs2025raybox,branchlessdda2016} accelerate the inner loop but do not address the fundamental algorithmic choice of \emph{what} to compute at each level.

\paragraph{Contributions.} This paper makes the following contributions:
\begin{enumerate}[leftmargin=*,itemsep=2pt]
  \item \textbf{Adaptive Hybrid Traversal (AHT):} A novel algorithm that selects between empty-space skipping, sparse early-termination, and branchless full traversal on a \emph{per-brick} basis, guided by precomputed local density metadata (Section~\ref{sec:method}).
  \item \textbf{Comprehensive benchmark framework:} Seven traversal algorithms evaluated across 441 configurations spanning five grid sizes, three densities, and three ray distributions, with statistical rigor (Sections~\ref{sec:setup}--\ref{sec:results}).
  \item \textbf{Branchless DDA with comparison masking:} An implementation that eliminates all conditional branches except loop termination, achieving $1.33\times$ speedup over standard DDA (Section~\ref{sec:method:branchless}).
  \item \textbf{Coherent ray batching with direction-based clustering:} A sorting scheme that groups rays by directional similarity, enabling shared-state vectorized traversal with up to $10\times$ throughput improvement (Section~\ref{sec:method:coherent}).
  \item \textbf{Scaling and sensitivity analysis:} Empirical characterization of algorithmic scaling ($\Theta(N^{-0.7})$ throughput) and density/coherence sensitivity, with crossover analysis identifying when hierarchical methods surpass flat traversal (Section~\ref{sec:results}).
\end{enumerate}

Section~\ref{sec:setup} describes the experimental setup.

\section{Related Work}
\label{sec:related}

\paragraph{Classic voxel traversal.}
Amanatides and Woo~\cite{amanatides1987fast} introduced the DDA algorithm that steps through a uniform grid by maintaining a \texttt{tMax} parameter for each axis, advancing along the axis with the smallest next-boundary crossing.
Each step requires two comparisons and one addition, giving $O(N)$ per-ray complexity where $N$ is the grid side length.
Siddon~\cite{siddon1985fast} proposed an equivalent formulation for medical CT path computation that precomputes all plane crossings, widely adopted in radiotherapy planning.
Cleary and Wyvill~\cite{cleary1988analysis} analyzed the supercover property and proved correctness guarantees for uniform subdivision traversal.
Bresenham's algorithm~\cite{bresenham1965algorithm}, originally designed for 2D rasterization, was extended to 3D voxel traversal using integer arithmetic~\cite{liu2004integer}.

\paragraph{Hierarchical and sparse methods.}
Laine and Karras~\cite{laine2010efficient} introduced Efficient Sparse Voxel Octrees (ESVO) with contour-based leaf nodes and beam optimization for GPU ray tracing, demonstrating that hierarchical traversal can dramatically reduce the number of voxel visits in sparse scenes.
K\"ampe et al.~\cite{kampe2013high} extended this with Sparse Voxel DAGs that achieve high compression through shared subtree merging.
The VoxelRT project~\cite{dubiousconst2024sparse64} introduced sparse 64-trees and bitmask-based \texttt{MultiDDA} that skips empty bricks using per-brick occupancy bitmasks, reporting 11--15\% improvement over ESVO on primary rays.

\paragraph{Spatial hashing and cache optimization.}
Nie{\ss}ner et al.~\cite{niessner2013voxelhashing} demonstrated real-time 3D reconstruction using voxel hashing, enabling efficient storage and traversal of sparse volumetric data.
Lefebvre and Hoppe~\cite{lefebvre2006perfect} proposed perfect spatial hashing for compact storage of sparse spatial data.
Morton codes~\cite{morton1966computer} (Z-order curves) reorder voxels for improved cache locality, reducing memory access latency during sequential traversal.

\paragraph{SIMD and GPU optimization.}
Es and Isler~\cite{es2007accelerated} accelerated regular grid traversal on GPUs using extended anisotropic chessboard distance fields.
Branchless DDA techniques~\cite{branchlessdda2016} replace conditional axis selection with arithmetic operations, reducing branch misprediction on modern processors.
Friederichs~\cite{friederichs2025raybox} proposed axis-normalized ray-box intersection optimized for SIMD execution.
NanoVDB~\cite{museth2021nanovdb} provides a GPU-friendly VDB data structure with efficient hierarchical traversal for production rendering.

\paragraph{Open-source implementations.}
Several reference implementations exist: Gyurgyik~\cite{cgyurgyik2020fvta} provides an optimized C++ DDA; Engelmann~\cite{engelmann2016fvt} offers a Python reference.
These serve as important baselines but implement only single-strategy flat traversal.

\paragraph{Positioning of our work.}
Unlike prior hierarchical methods that apply uniform two-level traversal, AHT \emph{adapts} its strategy per-brick based on precomputed density.
Unlike pure branchless or SIMD approaches that optimize the inner loop, AHT reduces the number of steps through macro-level skipping.
Our approach is complementary to GPU and SIMD optimizations and would yield compounding benefits in a compiled implementation.

\subsection{Standard DDA Traversal}

The Amanatides--Woo DDA~\cite{amanatides1987fast} traverses a ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ through a uniform grid $\mathcal{G}$ by maintaining, for each axis $a \in \{x, y, z\}$, the parameter $t_{\max}^{(a)}$ at which the ray next crosses a voxel boundary along axis $a$.
At each step, the algorithm advances along the axis $a^* = \arg\min_a t_{\max}^{(a)}$ and updates:
\begin{equation}
  \label{eq:dda_step}
  t_{\max}^{(a^*)} \leftarrow t_{\max}^{(a^*)} + \Delta t^{(a^*)}, \quad
  v_{a^*} \leftarrow v_{a^*} + \text{step}_{a^*}
\end{equation}
where $\text{step}_{a^*} \in \{-1, +1\}$ is the sign of $d_{a^*}$.
The traversal terminates when the ray exits the grid bounds.
The per-step cost is $O(1)$ (two comparisons, one addition), and the total cost per ray is $O(N)$ since the average number of voxels intersected scales linearly with the grid diagonal.

\subsection{Hierarchical Two-Level Traversal}

A two-level traversal divides $\mathcal{G}$ into $\lceil N/B \rceil^3$ bricks of size $B^3$.
A coarse-level DDA traverses the brick grid; for each brick $\mathcal{B}$ intersected, a fine-level DDA traverses the individual voxels within $\mathcal{B}$.
If a brick is entirely empty ($\rho(\mathcal{B}) = 0$), the fine-level traversal is skipped entirely.
This reduces total work from $O(N)$ to $O(N/B + K \cdot B)$ where $K$ is the number of occupied bricks intersected.

\section{Method}
\label{sec:method}

\subsection{Overview}

We present three algorithmic innovations that compose into the Adaptive Hybrid Traversal:
\begin{enumerate}[leftmargin=*]
  \item \textbf{Branchless DDA} (\S\ref{sec:method:branchless}): eliminates conditional branches in the axis selection step.
  \item \textbf{Density-adaptive per-brick strategy selection} (\S\ref{sec:method:adaptive}): the core novelty of this work.
  \item \textbf{Coherent ray batching} (\S\ref{sec:method:coherent}): direction-based clustering for vectorized group traversal.
\end{enumerate}

% ── 4.1 Branchless DDA ──────────────────────────────────────────────────────
\subsection{Branchless DDA with Comparison Masking}
\label{sec:method:branchless}

The standard DDA inner loop uses nested conditionals to determine the axis with the smallest $t_{\max}$:
\begin{equation}
  a^* = \begin{cases} x & \text{if } t_{\max}^{(x)} \leq t_{\max}^{(y)} \text{ and } t_{\max}^{(x)} \leq t_{\max}^{(z)} \\ y & \text{if } t_{\max}^{(y)} \leq t_{\max}^{(z)} \\ z & \text{otherwise} \end{cases}
\end{equation}
This requires 2--3 conditional branches per step, causing pipeline stalls on modern processors when rays are incoherent~\cite{branchlessdda2016}.

We replace this with comparison masking.
Define boolean masks:
\begin{align}
  c_{xy} &= [t_{\max}^{(x)} \leq t_{\max}^{(y)}], \quad
  c_{xz} = [t_{\max}^{(x)} \leq t_{\max}^{(z)}], \quad
  c_{yz} = [t_{\max}^{(y)} \leq t_{\max}^{(z)}]
\end{align}
Then the step is computed without branches:
\begin{align}
  \text{step}_x &= c_{xy} \cdot c_{xz} \cdot \text{sign}(d_x) \\
  \text{step}_y &= (1 - c_{xy}) \cdot c_{yz} \cdot \text{sign}(d_y) \\
  \text{step}_z &= (1 - c_{xz}) \cdot (1 - c_{yz}) \cdot \text{sign}(d_z)
\end{align}
and all three $t_{\max}$ values are updated simultaneously:
\begin{equation}
  t_{\max}^{(a)} \leftarrow t_{\max}^{(a)} + \Delta t^{(a)} \cdot [\text{step}_a \neq 0]
\end{equation}
The only remaining conditional branch is the loop termination check, reducing branch mispredictions from $O(3N)$ to $O(N)$.

% ── 4.2 Adaptive Hybrid Traversal ──────────────────────────────────────────
\subsection{Adaptive Hybrid Traversal}
\label{sec:method:adaptive}

The core contribution of this paper is a density-adaptive two-level traversal that selects the optimal strategy per-brick.

\subsubsection{Grid Construction}

Given a voxel grid $\mathcal{G}$ of size $N^3$, we construct an \texttt{AdaptiveGrid} by partitioning into $\lceil N/B \rceil^3$ bricks of size $B^3$ (with $B = 8$).
For each brick $\mathcal{B}_{x,y,z}$, we precompute:
\begin{itemize}[itemsep=1pt]
  \item $\text{occupied}(\mathcal{B}) \in \{0,1\}$: whether any voxel in the brick is occupied.
  \item $\rho(\mathcal{B}) \in [0,1]$: the fraction of occupied voxels in the brick.
\end{itemize}
Construction is $O(N^3)$ and is amortized over all ray queries.

\subsubsection{Traversal Algorithm}

\begin{algorithm}[t]
\caption{Adaptive Hybrid Traversal (AHT)}
\label{alg:aht}
\begin{algorithmic}[1]
\REQUIRE Adaptive grid $\mathcal{A}$, ray $(\mathbf{o}, \mathbf{d})$, threshold $\tau$
\ENSURE Ordered list of intersected voxels with $t$-parameters
\STATE Compute ray--grid intersection $[t_{\min}, t_{\max}]$
\IF{$t_{\min} > t_{\max}$}
  \RETURN $\emptyset$ \COMMENT{Ray misses grid}
\ENDIF
\STATE Initialize coarse DDA at brick level ($N/B$ grid)
\STATE $\text{result} \leftarrow \emptyset$
\WHILE{ray within brick grid bounds}
  \STATE $(bx, by, bz) \leftarrow$ current brick coordinates
  \IF{$\neg\, \text{occupied}(\mathcal{B}_{bx,by,bz})$}
    \STATE \textbf{Skip:} advance to next brick \COMMENT{Empty-space skip}
  \ELSIF{$\rho(\mathcal{B}_{bx,by,bz}) < \tau$}
    \STATE \textbf{Sparse DDA:} fine branchless DDA with early termination
  \ELSE
    \STATE \textbf{Dense DDA:} full branchless DDA within brick
  \ENDIF
  \STATE Advance coarse DDA (branchless axis selection)
\ENDWHILE
\RETURN $\text{result}$
\end{algorithmic}
\end{algorithm}

Algorithm~\ref{alg:aht} describes the AHT procedure.
The key innovation is the three-way dispatch at line 8--13: rather than uniformly applying fine-level DDA to all bricks (as in standard hierarchical traversal), AHT selects the strategy based on $\rho(\mathcal{B})$.
This ensures that:
\begin{itemize}[itemsep=1pt]
  \item \textbf{Empty bricks} ($\rho = 0$) are skipped in $O(1)$, saving up to $B^3 = 512$ voxel visits per brick.
  \item \textbf{Sparse bricks} ($0 < \rho < \tau$) use fine DDA with potential early termination, reducing unnecessary traversal through mostly-empty space.
  \item \textbf{Dense bricks} ($\rho \geq \tau$) use full branchless DDA, avoiding the overhead of density-checking at the voxel level.
\end{itemize}

\subsubsection{Complexity Analysis}

Let $K_e$, $K_s$, $K_d$ be the number of empty, sparse, and dense bricks intersected by a ray, respectively.
The per-ray cost is:
\begin{equation}
  T_{\text{AHT}} = O\!\left(\frac{N}{B}\right) + K_s \cdot O(B) + K_d \cdot O(B) = O\!\left(\frac{N}{B} + (K_s + K_d) \cdot B\right)
\end{equation}
For sparse grids where $K_e \gg K_s + K_d$, this reduces to $O(N/B)$, a factor of $B$ improvement over flat DDA.
For dense grids where $K_d \approx N/B$, AHT reduces to standard hierarchical cost plus constant dispatch overhead.

% ── 4.3 Coherent Ray Batching ───────────────────────────────────────────────
\subsection{Coherent Ray Batching}
\label{sec:method:coherent}

For applications processing many rays simultaneously (e.g., primary rays in rendering), we propose a direction-based clustering scheme that groups rays by directional similarity.

\subsubsection{Direction Hashing}

Each ray direction $\mathbf{d}$ is classified into one of $8 \times n_b^2$ bins, where 8 is the number of octants (sign combinations of $d_x, d_y, d_z$) and $n_b$ is the angular resolution per octant.
Within each octant, directions are binned by spherical angle quantization:
\begin{equation}
  h(\mathbf{d}) = 8 \cdot \left\lfloor n_b \cdot \frac{\theta}{\pi/2} \right\rfloor + \left\lfloor n_b \cdot \frac{\phi}{\pi/2} \right\rfloor + \text{octant}(\mathbf{d}) \cdot n_b^2
\end{equation}

\subsubsection{Shared-State Traversal}

Rays within the same directional bin share the same sign-step vector $\text{step} \in \{-1,+1\}^3$ and similar $\Delta t$ values.
This enables vectorized DDA where the step computation is broadcast across all rays in the group:
\begin{equation}
  \mathbf{v}^{(i)} \leftarrow \mathbf{v}^{(i)} + \text{step} \cdot \mathbf{m}^{(i)}, \quad \forall i \in \text{group}
\end{equation}
where $\mathbf{m}^{(i)}$ is the per-ray axis mask computed via comparison masking.

\subsubsection{Coherence Threshold}

The batching overhead (sorting, group creation) must be amortized over the vectorization benefit.
We empirically determine the crossover: batching is beneficial when the angular spread is $\leq 0.5$ radians (producing $\leq 235$ groups for $n_b = 8$), achieving $1.2$--$10\times$ speedup.
Beyond this spread, sorting overhead dominates.

% ── 4.4 Additional Optimizations ────────────────────────────────────────────
\subsection{Cache-Aware Morton Layout}
\label{sec:method:morton}

To improve cache performance, we implement a Morton-code (Z-order curve)~\cite{morton1966computer} grid layout.
The 3D voxel index $(i,j,k)$ is mapped to a 1D index by interleaving the bits of $i$, $j$, and $k$:
\begin{equation}
  M(i,j,k) = \text{spread}(i) \,|\, (\text{spread}(j) \ll 1) \,|\, (\text{spread}(k) \ll 2)
\end{equation}
This ensures that spatially adjacent voxels are stored in nearby memory locations, improving L2/L3 cache hit rates during sequential traversal.

\subsection{SIMD-Vectorized Batch DDA}
\label{sec:method:simd}

For batch processing, we implement a fully vectorized DDA that processes $N_r$ rays simultaneously using array operations.
All per-ray state ($t_{\max}$, voxel coordinates, step directions) is stored as $(N_r \times 3)$ arrays, and each traversal step operates on the entire batch via element-wise comparisons and updates:
\begin{equation}
  a^{*(i)} = \arg\min_a t_{\max}^{(i,a)}, \quad \forall i \in [1, N_r]
\end{equation}
This amortizes Python interpreter overhead across all rays, achieving $6.65\times$ speedup in count-only mode.

\subsection{Algorithms Evaluated}

\subsection{Metrics}

\begin{itemize}[itemsep=1pt]
  \item \textbf{Throughput} (rays/second): Primary performance metric, computed as $N_{\text{rays}} / T_{\text{mean}}$.
  \item \textbf{Average voxels/ray}: Number of voxels traversed per ray, measuring algorithmic work.
  \item \textbf{Speedup}: Ratio of throughput to baseline DDA throughput.
  \item \textbf{Scaling exponent}: Fitted power-law $\text{throughput} \propto N^{\alpha}$ via log-log regression.
\end{itemize}

\subsection{Hardware and Software}

All experiments were conducted using CPython with NumPy for vectorized operations.
Timing uses \texttt{time.perf\_counter\_ns} for sub-microsecond precision.
The pure Python implementation isolates algorithmic performance from hardware-specific optimizations (SIMD intrinsics, GPU), ensuring that measured speedups reflect fundamental algorithmic improvements that would transfer to any compiled implementation.

\subsection{Correctness Validation}

All seven algorithms pass a comprehensive test suite of 180 tests achieving 98\% code coverage, including:
\begin{itemize}[itemsep=1pt]
  \item No false positives: every reported voxel geometrically intersects the ray.
  \item No false negatives: comparison against brute-force reference on grids up to $64^3$.
  \item Edge cases: axis-aligned rays, corner-grazing rays, near-zero direction components, all 26 directional octants.
  \item Cross-algorithm consistency: all algorithms produce identical voxel sets.
  \item $t$-value monotonicity: reported $t$-parameters are strictly non-decreasing.
\end{itemize}

\section{Discussion}
\label{sec:discussion}

\subsection{Implications}

\paragraph{Adaptive strategy selection is the right abstraction.}
Our results demonstrate that no single traversal strategy is optimal across all grid configurations.
The branchless DDA excels on dense, uniform grids (Table~\ref{tab:main_results}); hierarchical DDA excels on structured sparse grids; SIMD batching excels for count-only batch workloads.
The AHT framework provides a principled way to compose these strategies, ensuring near-optimal performance regardless of local grid characteristics.

\paragraph{Structured vs.\ random sparsity.}
A critical finding is that hierarchical methods only benefit from \emph{structured} sparsity (Figure~\ref{fig:sensitivity:density}).
Random occupancy at even 5\% density leaves virtually no empty $8^3$ bricks, negating the skip benefit.
This implies that the practical value of hierarchical traversal depends heavily on the application domain: medical imaging (organ surfaces in empty tissue), voxel games (terrain surfaces enclosing empty volumes), and architectural scenes all exhibit structured sparsity, while Monte Carlo particle simulations may not.

\paragraph{Coherence exploitation.}
The coherent batching results (Table~\ref{tab:coherence_threshold}) show that exploiting ray coherence can provide order-of-magnitude speedups.
This is particularly relevant for primary ray casting in rendering, where rays from a camera share similar directions, and for cone-beam CT reconstruction, where rays fan out from a single source.

\subsection{Limitations}

\paragraph{Python implementation overhead.}
Our implementations are in pure Python (with NumPy for vectorization), which incurs 3--4 orders of magnitude overhead compared to optimized C++.
While this does not affect the validity of relative speedup measurements, it means absolute throughput numbers are not directly comparable to production systems.
The SIMD batch mode is particularly affected: result collection (building Python lists of tuples) dominates cost, limiting full-result mode to $0.81\times$ of scalar DDA despite achieving $6.65\times$ in count-only mode.

\paragraph{Construction overhead.}
The AdaptiveGrid construction is $O(N^3)$, which is amortized over all ray queries but may be prohibitive for single-ray use cases or highly dynamic grids that change between queries.

\paragraph{Dense grid overhead.}
AHT incurs $\sim 0.3\times$ overhead on uniformly dense grids due to the two-level dispatch.
For applications where grids are known to be uniformly dense, flat branchless DDA remains the optimal choice.

\paragraph{Brick size sensitivity.}
We use a fixed brick size of $B = 8$.
Smaller bricks ($B = 4$) would provide finer skip granularity but increase dispatch overhead; larger bricks ($B = 16$) would reduce overhead but miss skip opportunities.
A thorough analysis of the optimal $B$ as a function of grid characteristics is left for future work.

\subsection{Comparison with Hierarchical Approaches}

Our AHT differs from existing hierarchical methods~\cite{laine2010efficient,dubiousconst2024sparse64,kampe2013high} in two key ways:
\begin{enumerate}[itemsep=1pt]
  \item \textbf{Density metadata}: Prior methods use binary occupancy (occupied/empty) at the coarse level. AHT additionally stores density, enabling a three-way dispatch rather than two-way.
  \item \textbf{Branchless fine-level DDA}: Prior hierarchical methods typically use standard branching DDA at the fine level. AHT uses comparison-masking branchless DDA, compounding the hierarchical benefit with per-step optimization.
\end{enumerate}

These differences make AHT particularly effective for grids with spatially varying density, where some regions are sparse (benefiting from skipping) and others are dense (benefiting from branchless DDA).

\section{Conclusion}
\label{sec:conclusion}

We have presented Adaptive Hybrid Traversal (AHT), a novel voxel grid traversal algorithm that dynamically selects between empty-space skipping, sparse early-termination, and branchless full DDA on a per-brick basis, guided by precomputed density metadata.
Our comprehensive evaluation across 441 benchmark configurations demonstrates:

\begin{enumerate}[leftmargin=*,itemsep=2pt]
  \item AHT achieves $2.1$--$4.7\times$ speedup on structured sparse grids over the classic Amanatides--Woo DDA, matching the performance of pure hierarchical methods while avoiding their worst-case overhead on dense regions.
  \item Branchless DDA with comparison masking provides a consistent $1.33\times$ improvement over standard DDA across all grid configurations.
  \item SIMD-vectorized batch processing achieves $6.65\times$ throughput in count-only mode by amortizing interpreter overhead across rays.
  \item Coherent ray batching with direction-based clustering provides up to $10\times$ speedup when ray angular spread is $\leq 0.01$ radians.
  \item AHT is never more than $0.7\times$ slower than the best flat algorithm on dense grids, providing robust cross-scenario performance.
\end{enumerate}

\paragraph{Future work.}
Several directions merit further investigation:
\begin{itemize}[itemsep=1pt]
  \item \textbf{C/CUDA implementation}: Translating AHT to a compiled language would realize the full benefit of branchless execution and SIMD vectorization, with expected compounding of algorithmic and hardware speedups.
  \item \textbf{Dynamic grid support}: Incremental updates to brick metadata as voxels change, enabling real-time applications.
  \item \textbf{Multi-level hierarchy}: Extending AHT from two levels to multi-level (e.g., $64^3 \to 8^3 \to 1^3$) for very large grids ($> 1024^3$).
  \item \textbf{Learned density thresholds}: Using machine learning to optimize the sparse threshold $\tau$ based on grid statistics and workload characteristics.
  \item \textbf{Integration with NanoVDB}~\cite{museth2021nanovdb}: Adapting AHT's density-adaptive dispatch for the VDB hierarchical data structure.
\end{itemize}
