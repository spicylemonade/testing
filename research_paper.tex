\begin{abstract}
We study the exact real Hadamard problem at order $668=4\cdot167$ from the strongest in-repository frontier anchor currently available: Eliahou's 2025 $64$-modular order-$668$ near-solution, recovered as a compact pair of length-$167$ binary sequences. The prompt asked for a cellular-automaton approach. The repository therefore tests, and then progressively redesigns, local cellular-automaton dynamics on that published frontier seed under a shared exactness harness.

The first result is negative. The executed one-packet defect-syndrome cellular automaton \texttt{H1\_defect\_syndrome\_ca\_64m}, benchmarked against greedy search, tabu search, simulated annealing, and stochastic hillclimbing, reaches exactness on two tiny solved controls but neither reaches exact orthogonality nor improves the canonical frontier objective $(13,2880,512)$. An exhaustive exact delta scan then sharpens the failure: all $334$ one-packet moves, all $55{,}611$ unordered two-packet moves, and all $9$ retained low-splash composite actions fail as depth-1 single actuators. The retained library reduces the median changed-lag footprint from $51$ to $9$, but still yields no improving single action. This is an exact locality barrier, not merely a failed pilot.

The second result is positive but narrow. The same barrier certificate finds the first verified escape at radius $1$, depth $2$ on the retained overlap graph. The hyperedge $[3,7]$, corresponding to the action sequence $[\texttt{q[53]},\texttt{q[136]}]$ followed by $[\texttt{q[29]},\texttt{s[29]},\texttt{q[114]},\texttt{s[114]}]$, produces the six-packet state $(13,2744,480)$, improving the frontier seed by $136$ in $\ell_1$ defect and by $32$ in maximum defect while preserving support $13$. A lag-core lattice-gas automaton rederives the same state through an explicit continuity law and passes a Williamson/Turyn/Goethals-Seidel/cocyclic/block-circulant leakage audit. A symmetry-quotient orbit automaton with one fixed $137$-signature rule table transfers the same improvement across the canonical seed and five frontier perturbation states. A stochastic population automaton does not separate from its zero-coupling ablation and is retired honestly.

No exact order-$668$ Hadamard matrix is found. The contribution is instead a precise structural answer to the cellular-automaton question. One-packet CA locality at order $668$ is fake-local and blocked at depth $1$, but actuator redesign plus short-horizon local coordination produces a reproducible, leakage-audited frontier improvement. Cellular automata do not solve Hadamard $668$ here, yet they do expose a concrete local mechanism that survives beyond the original H1 falsification.
\end{abstract}

\section{Introduction}

An $n\times n$ real Hadamard matrix is a $\pm1$ matrix $H$ satisfying
\begin{equation}
HH^\top = nI_n.
\end{equation}
The Hadamard existence problem is both elementary to state and difficult to close. Large construction catalogues, modular variants, and certificate-rich structured searches coexist with stubborn open orders \citep{cati2024,eliahou2005,bright2019}. The present repository studies one such order: $668=4\cdot167$.

The exact target is not a modular surrogate. It is an exact real Hadamard matrix of order $668$. The strongest seed available in-repository is instead Eliahou's 2025 $64$-modular Hadamard matrix of order $668$, encoded compactly by two length-$167$ sign sequences with exactly $13$ nonzero combined correlation coefficients \citep{eliahou2025_64mod668}. The project therefore begins from a published near-solution, not from an exact witness.

The user asked for a method that had not yet been tried and named it ``cellar automata.'' The repository contains no independent technical meaning for that phrase, so the only coherent interpretation is \emph{cellular automata}. That interpretation immediately forces two standards of honesty.
\begin{enumerate}[label=\arabic*.,leftmargin=2em]
\item A CA result does not count as a solution unless exact orthogonality is reached.
\item A CA result does not count as a new method contribution merely because local-rule language is used; the update geometry must do something materially different from direct scoring or familiar design-generation patterns.
\end{enumerate}

The history of this repository now contains both a failure and a follow-up. The original H1 branch, a one-packet defect-syndrome CA in the recovered $q/s$ coordinates, fails cleanly under matched controls. The later retained-library branches, added after the H1 draft paper but before the current writing pass, do \emph{not} solve order $668$ either. They do, however, sharpen the answer in a way the stale draft does not: they certify a depth-1 locality barrier and then exhibit the first local counterexample class that crosses it.

The resulting paper is therefore not a frontier-solution paper. It is a barrier-and-counterexample paper on a concrete open order. Its contributions are the following.
\begin{enumerate}[label=\textbf{C\arabic*.},leftmargin=2.8em]
\item We formalize the recovered order-$668$ frontier seed, the shared exactness harness, and the exact packet/composite delta algebra used throughout the repository.
\item We preserve the original H1 result as a rigorously benchmarked negative control: H1 solves tiny exact controls but neither reaches exactness nor improves the canonical frontier seed.
\item We exhaustively enumerate a retained low-splash composite actuator library and prove, by exact finite computation, that all depth-1 single actuators in the checked class are blocked on the canonical seed.
\item We certify the first escaping local rule class: a radius-1, depth-2 retained hyperedge rule whose first counterexample reaches the six-packet state $(13,2744,480)$.
\item We show that the same non-exact frontier improvement is reproduced by a lag-core lattice-gas CA with an explicit continuity law and by a symmetry-quotient orbit CA with a single fixed rule table.
\item We show that a population self-stabilizing CA does not establish a robustness advantage over zero-coupling and therefore does \emph{not} justify a stronger self-organization claim.
\end{enumerate}

The paper is organized as follows. Section~\ref{sec:related} positions the work against modular Hadamard constructions, exact and heuristic search, and CA-adjacent design literature. Section~\ref{sec:background} defines the order-$668$ representation, the objective, the retained action graph, and the orbit signatures. Section~\ref{sec:method} gives the complete algorithmic pipeline, including pseudocode and complexity analysis. Section~\ref{sec:theory} states and proves the exact delta identities, the continuity law, the locality barrier, and the counterexample theorem. Section~\ref{sec:setup} documents all experiment inputs, budgets, seeds, and reproducibility limits. Section~\ref{sec:results} reports the negative H1 evidence, the retained-library barrier, the post-H1 branch outcomes, and the failed population robustness test. Section~\ref{sec:discussion} explains what the results establish, what remains open, and where the current evidence still stops short.

\section{Related Work}
\label{sec:related}

\subsection{Order 668 and the modular frontier}

The relevant frontier anchor is precise. Eliahou and Kervaire developed the modular-sequence framework and its relation to modular Hadamard matrices \citep{eliahou2001,eliahou2005}. Eliahou's 2025 order-$668$ construction then supplies the exact near-solution used in every frontier experiment of this paper: a compact length-$167$ seed whose derived Goethals-Seidel lift is Hadamard modulo $64$ and whose nonzero-lag defect profile contains exactly $13$ exceptional coefficients \citep{eliahou2025_64mod668}. Our paper does not claim a new order-$668$ seed, a new modular theorem, or a new exact witness. The Eliahou paper is the provenance source and the novelty ceiling.

\subsection{Exact and heuristic Hadamard search}

Exact combinatorial search remains the strongest evidence standard. Bright and collaborators show how SAT+CAS methods can certify exhaustive search statements for structured Hadamard-adjacent families such as Williamson and best matrices \citep{bright2018,bright2019}. This line matters here mainly as a contrast: our repository returns no exact order-$668$ witness and no proof of nonexistence. The present work is heuristic and local, not certificate-rich exact search.

Within heuristic search, Suksmono and collaborators study simulated quantum annealing, quantum annealing, and related optimization formulations for Hadamard search \citep{suksmono2018,suksmono2019,suksmono2022}. These are the relevant comparator papers for any broad statement about search competitiveness. We therefore avoid such statements. The saved repository evidence is strong enough to eliminate branches, but not to rank CA against the full annealing literature.

\subsection{Cellular automata as search and design machinery}

Cellular automata are not new in the most general sense. Tsompanas et al.\ use CA as a distributed local-search mechanism for the shortest path problem \citep{tsompanas2017}. That paper is not Hadamard-specific, but it blocks any claim that ``CA for search'' is itself novel. CA also appear in adjacent combinatorial-design settings: mutually orthogonal Latin squares from CA \citep{mariot2019_mols} and bent-function constructions from CA \citep{gadouleau2020}. Those papers matter for a different reason. They show that CA can contribute structurally to combinatorial design, but they also show that our claim must stay narrow. We are not presenting a new CA construction of a Hadamard family. We are studying one seed-specific repair program and the locality structure it induces.

\subsection{How the present work differs}

The repository's prior-art gap file is explicit about the limits of novelty. Relative to Eliahou's 2025 order-$668$ paper, we contribute only downstream search dynamics on top of the published seed. Relative to Tsompanas et al., we are not making a general CA-for-optimization claim, but a specific locality claim on one open Hadamard instance. Relative to Suksmono's Hadamard-search heuristics and Bright's exact-search line, we are narrower in scope and weaker in certification. Relative to the CA-based design-construction papers, we are not generating a new combinatorial family. The surviving contribution is therefore exact and local: an explicit barrier/counterexample pair for cellular-automaton search on the published order-$668$ frontier seed.

\section{Background and Preliminaries}
\label{sec:background}

\subsection{Recovered order-668 seed}

Let $\ell=167$. The repository stores the frontier seed as two sequences
\begin{equation}
q,s\in\pmone^\ell,
\end{equation}
decoded from Eliahou's published run-length encoding. Indices always run from $0$ to $\ell-1$.

\begin{definition}[Prime involution]
\label{def:prime-involution}
For $x\in\pmone^\ell$, define
\begin{equation}
x'_i =
\begin{cases}
x_i, & 0 \le i < (\ell+1)/2,\\
-x_i, & (\ell+1)/2 \le i \le \ell-1.
\end{cases}
\end{equation}
\end{definition}

Define the pointwise product $(q\odot s)_i=q_i s_i$. The shared harness uses the derived quadruple
\begin{equation}
A=s,\qquad B=s',\qquad C=q\odot s,\qquad D=(q\odot s)'.
\label{eq:derived-quad}
\end{equation}
The seed manifest \path|results/frontier/order_668_64m/seed_manifest.json| and source excerpt \path|results/frontier/order_668_64m/source_excerpt.txt| verify that this lift reproduces exactly the published $13$ exceptional coefficients.

\begin{definition}[Aperiodic autocorrelation]
\label{def:aperiodic}
For $x\in\pmone^\ell$ and lag $k\in\{0,1,\dots,\ell-1\}$, define
\begin{equation}
N_x(k)=\sum_{t=0}^{\ell-k-1} x_t x_{t+k}.
\label{eq:aperiodic}
\end{equation}
\end{definition}

The combined coefficient vector is
\begin{equation}
c_k(q,s)=N_A(k)+N_B(k)+N_C(k)+N_D(k),\qquad k=0,\dots,\ell-1.
\label{eq:combined-coeffs}
\end{equation}
By construction $c_0=4\ell=668$.

\begin{definition}[Primary defect tuple]
\label{def:objective}
For a state $(q,s)$, define
\begin{align}
\operatorname{support}(q,s) &= \left|\{k\in\{1,\dots,\ell-1\}: c_k(q,s)\neq 0\}\right|,\\
\operatorname{\ell_1}(q,s) &= \sum_{k=1}^{\ell-1}|c_k(q,s)|,\\
\operatorname{max}(q,s) &= \max_{1\le k\le \ell-1}|c_k(q,s)|.
\end{align}
The scalar proxy used internally for search is
\begin{equation}
\score(q,s)=10^6\operatorname{support}(q,s)+10^3\operatorname{\ell_1}(q,s)+\operatorname{max}(q,s).
\label{eq:score}
\end{equation}
\end{definition}

The canonical frontier seed starts at
\begin{equation}
\bigl(\operatorname{support},\operatorname{\ell_1},\operatorname{max}\bigr)=(13,2880,512),
\end{equation}
with nonzero lags exactly at
\begin{equation}
\{4,8,12,16,26,30,34,38,42,46,50,54,58\}.
\label{eq:seed-support}
\end{equation}
Figure~\ref{fig:seed-profile} visualizes the recovered sequences and the combined correlation profile.

\subsection{Packets, composite actions, and retained actions}

The raw packet basis is
\begin{equation}
\Pk=\{0,1,\dots,2\ell-1\}.
\end{equation}
Packets $0$ through $\ell-1$ flip one coordinate of $q$, while packets $\ell$ through $2\ell-1$ flip one coordinate of $s$. For a packet set $I\subseteq\Pk$, application is parity-based: flipping the same packet twice cancels.

\begin{definition}[Composite action]
\label{def:composite-action}
A composite action is a finite packet multiset, interpreted modulo parity. Its active $q$- and $s$-toggle sets are the odd-multiplicity packet indices in each channel.
\end{definition}

The composite-library scan enumerates five explicit actuator families around the canonical seed:
\begin{enumerate}[label=(\roman*),leftmargin=2em]
\item all unordered packet pairs,
\item all channel-complete four-packet actions $\{q[i],s[i],q[j],s[j]\}$ with $i<j$,
\item all matched boundary quads on run boundaries,
\item all $s$-boundary pairs,
\item all $q$-boundary pairs.
\end{enumerate}

The direct one-packet median changed-lag footprint is $51$, so the post-H1 pipeline defines the \emph{low-splash cutoff} as $25.5$, exactly half of that median. Inside the low-splash composite set, the repository retains the Pareto frontier over
\[
(\text{changed\_lag\_count},\ \operatorname{support},\ \operatorname{\ell_1},\ \operatorname{max}).
\]
This produces a retained library
\begin{equation}
\Ret=\{a_0,\dots,a_8\}
\end{equation}
of $9$ actions with median changed-lag count $9$.

\subsection{Retained-state graph and causal cones}

Each retained action $a_i\in\Ret$ has a changed-lag set $\Gamma(a_i)\subseteq\{1,\dots,\ell-1\}$. The retained-state graph is built by XOR-combining subsets of the retained actions. Since $|\Ret|=9$, there are at most $2^9=512$ subset masks. The constructor in \texttt{hadamard\_ca/retained\_state\_graph.py} exhausts all $512$ masks and, in the actual artifact, finds $512$ unique parity states.

\begin{definition}[Retained state graph]
\label{def:state-graph}
The retained state graph $G_{\Ret}=(\State,\Ret,E)$ has
\begin{itemize}[leftmargin=1.8em]
\item one state $s\in\State$ for each unique parity packet mask induced by a subset of $\Ret$,
\item one immediate transition $s\to s\oplus a_i$ for each retained action $a_i$,
\item one pairwise neighborhood edge between $a_i$ and $a_j$ if $\Gamma(a_i)\cap\Gamma(a_j)\neq\varnothing$,
\item one \emph{causal-cone} hyperedge $(a_i,a_j)$ when the pairwise-overlap condition holds and
\[
|\Gamma(a_i)\cup\Gamma(a_j)|\le 25.
\]
\end{itemize}
\end{definition}

The graph constructor stores the exact coefficient vector and objective tuple for every retained state, so the runtime branches never need to rescan the original $334$ packet basis once the retained graph is built.

\subsection{Lag field and orbit signatures}

For any retained state, define the signed lag-defect field
\begin{equation}
\rho(k)=c_k,\qquad k=1,\dots,\ell-1.
\end{equation}
The lattice-gas branch works directly on the transition signature of $\rho$, while the orbit branch quotients candidate events by the tuple
\begin{equation}
\sigma(e)=\bigl(\kappa(e),a(e),u(e),b(e),t(e),r(e)\bigr),
\label{eq:orbit-signature}
\end{equation}
where
\begin{itemize}[leftmargin=1.8em]
\item $\kappa(e)$ is the normalized event kind (\texttt{annihilation}, \texttt{move}, or \texttt{split}),
\item $a(e)\in\{1,2\}$ is the action count,
\item $u(e)\in\{\texttt{decrease},\texttt{conserve},\texttt{increase}\}$ is the support-flux class,
\item $b(e)\in\{\texttt{1},\texttt{2},\texttt{3\_4},\texttt{5\_8},\texttt{9\_plus}\}$ is the changed-lag-count bin,
\item $t(e)\in\{\texttt{tight},\texttt{mid},\texttt{wide}\}$ is the transport-span bin,
\item $r(e)$ is the canonical sign-run count of the delta profile.
\end{itemize}
By construction $\sigma(e)$ discards raw cyclic coordinates, is invariant under reversal, and ignores global $q/s$ sign orientation.

\section{Method}
\label{sec:method}

\subsection{Shared harness and exactness contract}

All methods report through the same harness in \texttt{hadamard\_ca/harness.py}. For every run, the harness computes
\begin{itemize}[leftmargin=1.8em]
\item exact-hit status (\texttt{exact\_hit}),
\item correlation-defect support,
\item off-diagonal Gram-defect support and maximum magnitude,
\item the objective tuple from Definition~\ref{def:objective},
\item wall time, objective-evaluation counts, restart counts, and a sign-quotiented fingerprint.
\end{itemize}
The harness is validated on exact controls of lengths $5$ and $7$ and is reused unchanged for the order-$668$ seed and the later retained-basis branches. The exactness gate is therefore identical throughout the paper.

\subsection{Negative-control stack: H1 and same-coordinate baselines}

The original H1 branch remains important because it is the control that failed cleanly enough to motivate the later redesign.

\paragraph{H1 defect-syndrome CA.}
The H1 state is
\[
(q,s,c,\Mask,r),
\]
where $q,s\in\pmone^{167}$, $c$ is the exact coefficient vector, $\Mask$ is a radius-1 active-lag neighborhood around the current defect support, and $r\in\mathbb{Z}_{\ge 0}^{334}$ is packet-level refractory memory. One H1 accepted-state update does the following.
\begin{enumerate}[label=\arabic*.,leftmargin=2em]
\item recompute the exact coefficient vector $c$,
\item build the active-lag mask $\Mask$,
\item evaluate the exact one-packet delta $\Delta_p$ for each $p\in\Pk$,
\item convert $\Delta_p$ into a raw packet pressure with active-lag bonuses and spill penalties,
\item smooth raw pressure over a packet graph with radius-2 same-channel edges and same-site cross-channel edges,
\item subtract refractory penalties and select locally maximal packets above threshold,
\item apply at most one packet, update the refractory field, and stop on exactness, stagnation, or budget exhaustion.
\end{enumerate}

The frontier H1 configuration is the saved one from \path|results/experiments/order_668_64m/configs/H1_defect_syndrome_ca_64m.json|: lag radius $1$, packet radius $2$, same-channel weight $0.15$, cross-channel weight $0.35$, activation threshold $0.5$, refractory steps $2$, stagnation limit $8$, requested restarts $3$, and restart packet flips $2$.

\paragraph{Same-coordinate non-CA baselines.}
Greedy search, tabu search, simulated annealing, and stochastic hillclimbing all operate on the same one-packet basis, the same $q/s$ state space, and the same scalar score \eqref{eq:score}. This matters because the H1 negative result is then attributable to the update rule rather than to a privileged state representation.

\paragraph{Complexity of H1.}
The exact coefficient recomputation and all-packets delta sweep dominate. With fixed neighborhood radii, one accepted-state H1 update costs $O(\ell^2)$ arithmetic and $O(\ell)$ working memory beyond the trace, exactly as in the original H1 paper draft.

\subsection{Algorithm 1: exhaustive actuator atlas and retention rule}

The post-H1 pass does not begin by tuning the H1 weights. It first changes the actuator basis.

\paragraph{Enumeration.}
Using the exact composite delta identity proved in Section~\ref{sec:theory}, the script \path|scripts/generate_composite_locality_atlas.py| evaluates
\begin{itemize}[leftmargin=1.8em]
\item $55{,}611$ unordered packet pairs,
\item $13{,}861$ channel-complete balanced-four actions,
\item $85$ matched boundary quads,
\item $84$ $s$-boundary pairs,
\item $3$ $q$-boundary pairs,
\end{itemize}
for a total of $69{,}644$ composite candidates on the canonical frontier seed, plus a harder control cross-check.

\paragraph{Retention.}
The low-splash cutoff is fixed at $25.5$, exactly half the one-packet median changed-lag footprint $51$. Inside the frontier low-splash set, the retained library is the Pareto frontier in changed-lag count and the three components of the defect tuple. This produces nine actions. Seven are pairs, two are balanced-four actions, and none individually improves the frontier seed.

\paragraph{Complexity.}
Let $M$ be the number of candidate composite actions and let $r$ be the maximum number of toggled coordinates in any candidate. After precomputing the single-site delta table, one candidate evaluation uses $O(\ell+r^2)$ time. Here $r\le 4$, so the entire atlas construction is $O(M\ell)$ with a small constant.

\subsection{Algorithm 2: retained-state hypergraph CA}

Once the retained library is fixed, the hypergraph CA no longer scans the original $334$ packets at runtime.

\paragraph{State graph.}
The retained-state graph has $9$ actions, $512$ states, $9$ immediate transitions from each state, and $56$ ordered two-step causal cones satisfying the retained overlap rule in Definition~\ref{def:state-graph}. The canonical run uses a lookup budget of $256$ graph transitions.

\paragraph{Immediate baselines.}
The same retained basis supports four depth-1 controls:
\begin{enumerate}[label=(\alph*),leftmargin=2em]
\item \texttt{pairwise\_graph\_ca}: coupled immediate search with one-step refractory,
\item \texttt{zero\_coupling}: immediate lexicographic search without coupling,
\item \texttt{zero\_refractory}: coupled immediate search without refractory blocking,
\item \texttt{scorer\_only}: uncoupled, unrefracted immediate search.
\end{enumerate}

\paragraph{Hypergraph rule.}
At each state, the hypergraph CA scans all admissible causal cones rooted at the local neighborhood, computes the exact end-state objective for each cone using the precomputed state graph, and accepts the lexicographically best improving cone if one exists. The canonical run accepts exactly one cone, then stops when the next scan shows no improving depth-2 move.

\paragraph{Runtime.}
With the retained graph precomputed, one full immediate scan is $O(|\Ret|)$ graph lookups and one full hypergraph scan is $O(|\Cone|)$ graph lookups, independent of the original $668\times668$ matrix. In the actual artifact, the canonical hypergraph run spends $210$ transition lookups and never rescans the raw packet basis.

\subsection{Algorithm 3: defect-charge lattice-gas CA}

The lattice-gas branch reinterprets the same retained basis in lag space. It works with the signed lag field $\rho$ and the transport signature induced by a candidate transition.

\paragraph{Candidate generation.}
The branch first evaluates all single retained actions. If any direct single action improves the current objective, it chooses among those. Otherwise it opens the precomputed two-step carrier cones. The candidate factory is therefore
\[
\text{singles first, then carriers only when singles are blocked.}
\]

\paragraph{Ranking.}
For each candidate, the branch computes
\[
(\text{support flux},\ \text{reservoir magnitude},\ \text{transport span},\ \text{warning overlap},\ -\ell_1\text{ gain},\ -\text{max gain}).
\]
Single actions are always admissible if they improve. Two-step carriers are admissible only when
\begin{equation}
\text{support flux}\le 0,\qquad |R|\le 16,\qquad \ell_1\text{ gain}>0.
\end{equation}
This rule is intentionally conservative: temporary support diffusion is allowed only inside a carrier macro-event whose final state returns to nonincreasing support.

\paragraph{Controls.}
Two matched lag-space controls are run on the same retained graph:
\begin{enumerate}[label=(\alph*),leftmargin=2em]
\item \texttt{lag\_greedy\_control}, which chooses the best improving single retained action,
\item \texttt{warning\_field\_control}, which preserves warning-memory bookkeeping but still restricts itself to single actions.
\end{enumerate}

\subsection{Algorithm 4: orbit-quotient CA}

The orbit CA removes raw coordinate dependence. For any state, it groups all improving single actions and two-step carriers by the signature \eqref{eq:orbit-signature}. Each signature class contributes exactly one representative event to the runtime decision set.

\paragraph{Training mix.}
The saved orbit rule table has $137$ signatures. It is trained from
\begin{itemize}[leftmargin=1.8em]
\item $24$ states from \texttt{control\_n5\_q0} with $162$ improving representatives,
\item $24$ states from \texttt{control\_n7\_q0} with $338$ improving representatives,
\item $64$ states from \texttt{control\_n9\_hardest\_pair} with $2259$ improving representatives,
\item four predefined frontier perturbation states with counts $3,3,1,1$.
\end{itemize}
The canonical frontier seed itself is \emph{not} part of training.

\paragraph{Runtime rule.}
At each state, the orbit CA forms the representative set, filters to improving representatives, and chooses the minimum event under
\[
(\text{rule priority},\ \text{fallback orbit rank},\ \text{lattice-gas rank}).
\]
The canonical frontier run reaches the improved state in $65$ representative lookups.

\subsection{Algorithm 5: population self-stabilizing CA}

The final branch keeps the orbit representation but adds a stochastic population layer.

\paragraph{Rule table.}
Unlike the orbit CA, the population branch uses a \emph{control-only} rule table of size $133$. It is trained on non-frontier controls only.

\paragraph{Dynamics.}
At each state, the algorithm:
\begin{enumerate}[label=\arabic*.,leftmargin=2em]
\item computes one base score per orbit representative,
\item adds coupling-weighted neighbor mass,
\item samples a population of votes through a Gumbel-softmax distribution,
\item updates a memory distribution over orbit representatives,
\item accepts the top representative only if it both improves the current score and exceeds a contraction threshold.
\end{enumerate}

The selected operating point is population size $64$, coupling strength $1.6$, temperature $1.2$, contraction threshold $0.42$, memory mix $0.55$, maximum rounds per step $6$, and RNG seeds $\{11,13,17,19,23\}$. The zero-coupling ablation sets the coupling strength to $0$ and leaves every other parameter unchanged.

\section{Theoretical Results and Proofs}
\label{sec:theory}

The theorems in this section do not prove Hadamard existence at order $668$. They instead certify the exact delta machinery, the lattice-gas continuity law, the depth-1 locality barrier, and the first escaping local rule class.

\begin{proposition}[Exact single-entry autocorrelation delta]
\label{prop:single-entry-delta}
Let $x\in\pmone^\ell$ and let $x^{(i)}$ denote the sequence obtained by flipping only coordinate $i$. Then for every lag $k\in\{1,\dots,\ell-1\}$,
\begin{equation}
N_{x^{(i)}}(k)-N_x(k)
= -2x_i x_{i+k}\mathbf{1}\{i+k<\ell\}
-2x_{i-k}x_i\mathbf{1}\{i-k\ge 0\}.
\label{eq:single-entry-delta}
\end{equation}
\end{proposition}

\begin{proof}
Fix a lag $k\ge 1$. By Definition~\ref{def:aperiodic},
\[
N_x(k)=\sum_{t=0}^{\ell-k-1}x_t x_{t+k}.
\]
We compare each summand in $N_x(k)$ with the corresponding summand in $N_{x^{(i)}}(k)$.

If neither $t$ nor $t+k$ equals $i$, then the $t$th summand is unchanged, because $x$ and $x^{(i)}$ differ only at coordinate $i$.

There are at most two changed summands.

\emph{Case 1: $t=i$.} This case occurs exactly when $i+k<\ell$. The original summand is $x_i x_{i+k}$, while the new summand is $(-x_i)x_{i+k}$. Their difference is
\[
(-x_i)x_{i+k}-x_i x_{i+k}=-2x_i x_{i+k}.
\]

\emph{Case 2: $t=i-k$.} This case occurs exactly when $i-k\ge 0$. The original summand is $x_{i-k}x_i$, while the new summand is $x_{i-k}(-x_i)$. Their difference is
\[
x_{i-k}(-x_i)-x_{i-k}x_i=-2x_{i-k}x_i.
\]

No other summand changes. Summing the contributions from the two cases gives \eqref{eq:single-entry-delta}. This proves the proposition.
\end{proof}

\begin{theorem}[Exact multi-toggle delta for a single sequence]
\label{thm:multi-toggle-delta}
Let $x\in\pmone^\ell$ and let $I\subseteq\{0,\dots,\ell-1\}$ be a finite set of toggled coordinates. Let $x^{(I)}$ be obtained by flipping every coordinate in $I$. For each lag $k\in\{1,\dots,\ell-1\}$,
\begin{equation}
N_{x^{(I)}}(k)-N_x(k)
= \sum_{i\in I}\delta_x(i,k)
+4\sum_{\substack{i<j\\ i,j\in I\\ j-i=k}}x_i x_j,
\label{eq:multi-toggle-delta}
\end{equation}
where $\delta_x(i,k)$ is the right-hand side of \eqref{eq:single-entry-delta}.
\end{theorem}

\begin{proof}
Fix a lag $k\ge 1$. For every valid pair $(t,t+k)$, define the original contribution
\[
u_t=x_t x_{t+k}.
\]
After flipping all coordinates in $I$, the same pair contributes
\[
u_t^{(I)} = \eta_t \eta_{t+k} x_t x_{t+k},
\]
where
\[
\eta_r=
\begin{cases}
-1, & r\in I,\\
1, & r\notin I.
\end{cases}
\]
Therefore the pair contribution changes by
\[
u_t^{(I)}-u_t = (\eta_t\eta_{t+k}-1)x_t x_{t+k}.
\]

There are three possibilities.
\begin{enumerate}[label=(\roman*),leftmargin=2em]
\item If neither endpoint belongs to $I$, then $\eta_t\eta_{t+k}=1$ and the pair contributes $0$.
\item If exactly one endpoint belongs to $I$, then $\eta_t\eta_{t+k}=-1$ and the pair contributes $-2x_t x_{t+k}$.
\item If both endpoints belong to $I$, then $\eta_t\eta_{t+k}=1$ and the pair again contributes $0$.
\end{enumerate}

Now consider the sum of the single-entry deltas $\sum_{i\in I}\delta_x(i,k)$. By Proposition~\ref{prop:single-entry-delta}, each toggled endpoint in a valid lag-$k$ pair contributes $-2x_t x_{t+k}$ to this sum. Hence:
\begin{enumerate}[label=(\alph*),leftmargin=2em]
\item a pair with exactly one toggled endpoint contributes exactly $-2x_t x_{t+k}$ to the single-entry sum, which matches the true multi-toggle change;
\item a pair with both endpoints toggled contributes $-4x_t x_{t+k}$ to the single-entry sum, even though the true multi-toggle change is $0$.
\end{enumerate}

Thus the single-entry sum is correct for all pairs except the pairs whose two endpoints are both toggled. For such a pair, say $(i,j)$ with $i<j$ and $j-i=k$, the overcount is exactly $-4x_i x_j$, so the correction needed is $+4x_i x_j$. Summing this correction over all toggled pairs at distance $k$ yields the second term in \eqref{eq:multi-toggle-delta}. No further correction is necessary, because every lag-$k$ pair contains at most two endpoints. Therefore \eqref{eq:multi-toggle-delta} holds for each $k$, proving the theorem.
\end{proof}

\begin{corollary}[Exact composite-action coefficient delta]
\label{cor:composite-delta}
Let a composite action toggle the $q$-indices $I_q$ and the $s$-indices $I_s$, and let
\[
I_{qs}=I_q\triangle I_s
\]
be their symmetric difference. Then the exact coefficient delta for the combined vector \eqref{eq:combined-coeffs} is
\begin{equation}
\Delta =
\Delta_s(I_s)+\Delta_{s'}(I_s)+\Delta_{q\odot s}(I_{qs})+\Delta_{(q\odot s)'}(I_{qs}),
\label{eq:combined-delta}
\end{equation}
where each $\Delta_x(I)$ is the lag vector from Theorem~\ref{thm:multi-toggle-delta} applied to sequence $x$ and toggle set $I$.
\end{corollary}

\begin{proof}
Flipping a subset of $q$ coordinates does not change $s$ or $s'$, while flipping a subset of $s$ coordinates changes both $s$ and $s'$ on exactly those coordinates. For the product sequence $q\odot s$, a coordinate changes sign exactly when an odd number of the corresponding $q$ and $s$ coordinates are toggled, which is precisely the symmetric-difference condition $I_q\triangle I_s$. The same statement holds for $(q\odot s)'$ because the prime involution multiplies coordinates by a fixed sign mask and therefore preserves the set of changed coordinates. Since the combined coefficient vector is the sum of the four autocorrelation vectors, the total coefficient delta is the sum of the four sequence-level deltas. Applying Theorem~\ref{thm:multi-toggle-delta} to each sequence yields \eqref{eq:combined-delta}.
\end{proof}

\begin{theorem}[Lag-field continuity law with a boundary reservoir]
\label{thm:continuity-law}
Let $L=\ell-1=166$. For any transition on the retained graph, define
\[
\rho_t(k)=c_k^{(t)},\qquad \Delta(k)=\rho_{t+1}(k)-\rho_t(k),\qquad 1\le k\le L.
\]
Let
\begin{equation}
R=\sum_{k=1}^{L}\Delta(k)
\end{equation}
and define the current
\begin{equation}
J(k)=-\sum_{i=1}^{k}\bigl(\Delta(i)-R\mathbf{1}\{i=L\}\bigr),\qquad k=0,1,\dots,L,
\label{eq:current-def}
\end{equation}
with the empty sum convention $J(0)=0$. Then for every $k\in\{1,\dots,L\}$,
\begin{equation}
\rho_{t+1}(k)-\rho_t(k)=J(k-1)-J(k)+R\mathbf{1}\{k=L\}.
\label{eq:continuity-law}
\end{equation}
\end{theorem}

\begin{proof}
Fix $k\in\{1,\dots,L\}$. By definition \eqref{eq:current-def},
\[
J(k-1)=-\sum_{i=1}^{k-1}\bigl(\Delta(i)-R\mathbf{1}\{i=L\}\bigr)
\]
and
\[
J(k)=-\sum_{i=1}^{k}\bigl(\Delta(i)-R\mathbf{1}\{i=L\}\bigr).
\]
Subtract the second identity from the first:
\begin{align*}
J(k-1)-J(k)
&=
-\sum_{i=1}^{k-1}\bigl(\Delta(i)-R\mathbf{1}\{i=L\}\bigr)
+\sum_{i=1}^{k}\bigl(\Delta(i)-R\mathbf{1}\{i=L\}\bigr)\\
&=\Delta(k)-R\mathbf{1}\{k=L\}.
\end{align*}
Rearranging gives
\[
\Delta(k)=J(k-1)-J(k)+R\mathbf{1}\{k=L\}.
\]
Since $\Delta(k)=\rho_{t+1}(k)-\rho_t(k)$ by definition, \eqref{eq:continuity-law} follows. Every step has been explicit, so the theorem is proved.
\end{proof}

\begin{proposition}[Orbit-signature invariance under reversal and sign flip]
\label{prop:orbit-invariance}
Let two candidate events have the same normalized event kind, action count, support flux, changed-lag count, and transport span, and suppose their delta profiles differ only by reversal and/or global sign inversion. Then they induce the same orbit signature \eqref{eq:orbit-signature}.
\end{proposition}

\begin{proof}
All components of \eqref{eq:orbit-signature} except the final one depend only on the quantities explicitly listed in the statement, so those components agree immediately.

It remains to check the sign-run count $r(e)$. The implementation computes $r(e)$ by extracting the sign sequence of the delta profile and then taking the minimum run-length encoding among the four variants
\[
\text{original},\quad \text{reversed},\quad \text{sign-flipped},\quad \text{reversed sign-flipped}.
\]
If one profile is obtained from the other by reversal and/or sign inversion, then the two sets of four variants are identical as sets. Therefore the minimum run-length encoding is the same for both events, and hence the run-count component $r(e)$ is the same. Thus all six components of \eqref{eq:orbit-signature} agree, proving the proposition.
\end{proof}

\begin{theorem}[Depth-1 locality barrier on the canonical frontier seed]
\label{thm:depth-one-barrier}
Let $\Act_1$ be the explicit actuator class consisting of
\begin{enumerate}[label=(\roman*),leftmargin=2em]
\item all $334$ one-packet moves,
\item all $55{,}611$ unordered two-packet moves,
\item all $9$ retained low-splash composite actions.
\end{enumerate}
Then no actuator in $\Act_1$ strictly improves the canonical frontier objective $(13,2880,512)$.
\end{theorem}

\begin{proof}
The statement is a complete finite computation recorded in \path|results/verification/radius_limited_locality_barrier.json|. The proof proceeds family by family.

\emph{One-packet family.} The direct locality scan \path|results/analysis/frontier_locality_scan.json| exhausts all $334$ packets and reports
\[
\text{better}=0,\qquad \text{equal}=1,\qquad \text{worse}=333.
\]
The unique neutral packet is \texttt{s[83]}.

\emph{Two-packet family.} The barrier checker evaluates all $55{,}611$ unordered two-packet actions by exact delta computation and reports no improving pair. The best pair is the neutral action
\[
[\texttt{s[84]},\texttt{s[166]}],
\]
which leaves the objective unchanged.

\emph{Retained composite family.} The same checker evaluates all $9$ retained low-splash actions and again finds no improving single actuator. The best retained action is the same neutral pair as above.

Since every member of $\Act_1$ belongs to one of the three families above, and each family has been checked exhaustively with no strict improvement, no actuator in $\Act_1$ improves the canonical frontier seed. This proves the theorem.
\end{proof}

\begin{theorem}[First certified depth-2 local counterexample]
\label{thm:first-counterexample}
In the retained radius-1, depth-2 causal-cone rule class, there exists a strict local improvement of the canonical frontier seed. The first certified counterexample in lexicographic checker order is the edge
\begin{equation}
[3,7]=\bigl([\texttt{q[53]},\texttt{q[136]}],\ [\texttt{q[29]},\texttt{s[29]},\texttt{q[114]},\texttt{s[114]}]\bigr),
\end{equation}
which reaches the six-packet state
\[
[\texttt{q[29]},\texttt{q[53]},\texttt{q[114]},\texttt{q[136]},\texttt{s[29]},\texttt{s[114]}]
\]
with objective $(13,2744,480)$.
\end{theorem}

\begin{proof}
The barrier certificate defines the checked rule class explicitly:
\begin{enumerate}[label=(\alph*),leftmargin=2em]
\item both actions must belong to the retained library $\Ret$,
\item the two actions must overlap on changed-lag support,
\item the union of their changed-lag sets must stay within the retained low-splash envelope of at most $25$ lags.
\end{enumerate}
The checker then enumerates every admissible ordered causal cone from the canonical seed state.

The action $a_3=[\texttt{q[53]},\texttt{q[136]}]$ is itself a depth-1 non-improving retained action with objective
\[
(14,2820,496).
\]
The action $a_7=[\texttt{q[29]},\texttt{s[29]},\texttt{q[114]},\texttt{s[114]}]$ is also depth-1 non-improving when applied directly to the seed. However, the ordered cone $(a_3,a_7)$ is admissible in the checked rule class and its end state, stored in the barrier JSON as state $53$, has objective
\[
(13,2744,480).
\]
To see that this is a strict improvement, compare it lexicographically with the seed objective:
\[
13=13,\qquad 2744<2880,\qquad 480<512.
\]
Hence the end state has the same support as the seed and strictly smaller $\ell_1$ and maximum defect. Therefore it strictly improves the objective.

The checker reports \texttt{counterexample\_count = 2} and stores the first counterexample exactly as the edge $[3,7]$ above. Thus the canonical seed is not blocked once the local rule class is widened from depth-1 single actuators to retained radius-1 depth-2 causal cones. This proves the theorem.
\end{proof}

\begin{proposition}[Artifact-certified failure of the H1 continuation gate]
\label{prop:h1-gate-failure}
In the original one-packet frontier batch, H1 fails all continuation conditions:
\begin{enumerate}[label=(\alph*),leftmargin=2em]
\item no exact hit,
\item no best-objective improvement over the seed,
\item no strict support-plus-magnitude advantage over the matched baselines.
\end{enumerate}
\end{proposition}

\begin{proof}
The frontier summary \path|results/experiments/order_668_64m/summary.json| records
\[
\texttt{exact\_hit}=\texttt{false}
\]
for H1 and
\[
\texttt{best\_objective}=(13,2880,512),
\]
which is exactly the seed tuple. This proves (a) and (b).

For (c), the same artifact records H1 terminal restart tuples
\[
(33,2368,384),\quad (40,2356,408),\quad (23,2216,384),
\]
with median terminal tuple $(33,2356,384)$. Greedy and simulated annealing each remain at $(13,2880,512)$. Therefore H1 does not hold a strict support advantage over those baselines, because $33>13$. Hence it fails the continuation gate on support even though some terminal magnitudes are lower. This proves (c).
\end{proof}

The barrier does not prove that local CA are hopeless. It proves that depth-$1$ is hopeless in the checked class. Figure~\ref{fig:barrier-transfer} visualizes the path and compares the retained-basis branches across the frontier ladder.

The hypergraph CA uses that exact rule class and beats every immediate retained-basis baseline on the canonical seed and on all five ladder states. On the canonical seed, it reaches the six-packet state $(13,2744,480)$ in one accepted update. The pairwise, zero-coupling, zero-refractory, and scorer-only baselines all remain stuck at the start state.

\subsection{The lattice-gas branch reproduces the same state and passes the family-leakage audit}

The hypergraph result might still be dismissed as a graph-local coincidence unless a different representation recovers it. The lattice-gas branch does exactly that. It works on the signed lag field, not on raw packet coordinates, and ranks transitions by the continuity-law signature from Theorem~\ref{thm:continuity-law}. On the canonical frontier seed it reaches the same improved state $(13,2744,480)$ while both lag-space single-action controls stay at $(13,2880,512)$. On the harder control \texttt{control\_n9\_hardest\_pair}, the lattice-gas branch reaches exactness $(0,0,0)$.

Equally important, the family-leakage audit passes. The improved frontier state shows no palindromic, prime-involution-fixed, cocyclic, block-circulant, or nontrivial periodic collapse in the derived channels. The branch therefore survives as a lag-space reinterpretation of the same local escape, not as a disguised search over a known restricted family.

\subsection{The orbit quotient transfers the same improvement across the perturbation ladder}

The orbit branch tests a stronger claim than the hypergraph or lattice-gas branches: can one fixed local rule table operate on symmetry-quotient classes rather than on raw packet identities? The answer in the saved artifacts is yes, but only for the same non-exact improvement. The orbit rule table has $137$ signatures and is trained without the canonical frontier seed itself. It improves all six frontier states shown in Figure~\ref{fig:barrier-transfer} and, on the canonical seed, reaches the target state in $65$ representative lookups instead of the hypergraph CA's $210$.

The orbit result therefore strengthens the repository's final position in one specific way. The retained counterexample is not merely a single coordinate-space trick. It survives quotienting by cyclic position, reversal, and global sign orientation through Proposition~\ref{prop:orbit-invariance}. It still does \emph{not} solve order $668$, but it does transfer the same frontier improvement beyond one raw-coordinate representation.

\subsection{Population self-stabilization fails to beat zero-coupling}

The population branch is the main robustness test. It asks whether stochastic coupling over orbit representatives can turn the retained local escape into a stronger self-organizing phenomenon. Figure~\ref{fig:population-phase} and Table~\ref{tab:population} show that it cannot, at least in the saved regime. On the canonical seed, the coupled and zero-coupling branches both improve in $3/5$ runs and both contract in $3/5$ runs. Across the perturbation ladder, the coupled population never achieves a strict majority of wins over zero-coupling. The phase map is diffusion-only at every tested coupling/threshold pair.

\section{Discussion}
\label{sec:discussion}

\subsection{What the repository now establishes}

The strongest answer to the original cellular-automaton question is no longer the stale H1 statement ``we tried CA and it failed.'' The current repository establishes four narrower and stronger facts.
\begin{enumerate}[label=\arabic*.,leftmargin=2em]
\item The original one-packet CA basis is genuinely blocked on the canonical seed, not merely unpromising.
\item The obstruction is not all local dynamics; it is depth-1 local actuation in the checked class.
\item A redesigned low-splash actuator basis plus depth-2 local coordination yields a reproducible six-packet state that strictly improves the frontier seed to $(13,2744,480)$.
\item That same improved state is not tied to one code path: it appears in the hypergraph, lattice-gas, and orbit branches.
\end{enumerate}
These are substantial structural facts even though they stop short of an exact Hadamard matrix.

\subsection{What the repository does \emph{not} establish}

The paper still does not justify any of the following stronger claims.
\begin{itemize}[leftmargin=1.8em]
\item Hadamard order $668$ is not solved.
\item No exact order-$668$ witness or impossibility proof is produced.
\item The retained-basis branches do not prove that cellular automata are broadly competitive with annealing, SAT+CAS, or other Hadamard-search paradigms.
\item The current evidence is not a literature-scale benchmark. It is one frontier seed, one retained-library perturbation ladder, and one population robustness sweep.
\item The post-H1 branches are supported by direct raw artifacts, but the repository does not contain a second full review-round narrative packet aligned to those later commits. We therefore keep the post-H1 claims empirical and local rather than sweeping and novelty-heavy.
\end{itemize}

\subsection{Failure modes and limitations}

Three limitations matter most.

\paragraph{Exactness remains open.}
All successful retained-basis branches converge to the same non-exact six-packet state. The paper does not know whether that state is a stepping stone toward an exact witness or a local dead end of a different kind.

\paragraph{The retained library is tiny and hand-fixed by a deterministic rule.}
The library has only nine actions because the retention rule is deliberately severe. That severity is a strength for barrier certification, but also a weakness: it may exclude other useful local mechanisms that require a slightly larger retained basis.

\paragraph{Hardware provenance is incomplete.}
The repository preserves configurations and outputs well, but not the machine profile. As a result, work accounting in this paper is lookup- or evaluation-based rather than hardware-normalized.

\subsection{Open questions}

The current barrier/counterexample pair suggests several concrete next questions.
\begin{enumerate}[label=\arabic*.,leftmargin=2em]
\item Does any retained-basis local rule reach a state with support below $13$?
\item Can a larger but still certifiable low-splash library produce deeper exact escapes without collapsing into global rescoring?
\item Is the six-packet state $(13,2744,480)$ unique up to the current equivalence notion inside the retained graph, or are there qualitatively different local escapes?
\item Can the retained-basis search be combined with exact subproblem certification without shifting all credit to the exact layer?
\end{enumerate}
These are the meaningful next steps. More H1 weight tuning is not.

\subsection{Societal and scientific implications}

The direct societal stakes are limited, since the target is an abstract combinatorial object. The scientific lesson is about method discipline. Open-problem work on near-solutions is especially vulnerable to rhetoric drifting ahead of exactness. The current repository avoids that failure only when the claim is phrased precisely: one-packet CA fails, retained depth-2 local escape succeeds narrowly, population robustness fails, and the exact order-$668$ problem remains open.

\section{Conclusion}

Cellular automata do not solve Hadamard order $668$ in this repository. The original H1 one-packet branch is a clean negative control: it reaches exactness on tiny controls but neither improves the canonical frontier seed nor survives the continuation gate. The post-H1 redesign then sharpens, rather than erases, that failure. Exact exhaustive evaluation over $55{,}954$ depth-1 single actuators proves a locality barrier on the canonical seed. The first verified escape appears only at radius $1$, depth $2$ on the retained overlap graph, reaching the six-packet state $(13,2744,480)$. The same state is reproduced by a lag-core lattice-gas CA and transferred by a symmetry-quotient orbit CA, while a population self-stabilizing CA fails to beat zero-coupling.

The honest answer to the user's request is therefore two-part. First, ``cellular automata'' did not find an exact Hadamard matrix of order $668$. Second, a carefully redesigned local CA pipeline did find a certified and reproducible frontier improvement, together with an exact barrier/counterexample description of why the original one-packet approach failed. That is not a solution paper. It is a rigorous negative-plus-narrow-positive structural result on a concrete open order.

\section{Additional Proof Details}

\subsection{State-count lemma for the retained graph}

\begin{lemma}
\label{lem:state-count}
The retained-state constructor produces exactly $512$ states on the canonical frontier seed.
\end{lemma}

\begin{proof}
There are $9$ retained actions, so there are exactly $2^9=512$ subsets of $\Ret$. The constructor enumerates all $512$ subset masks and maps each mask to its parity packet mask. By definition, the number of retained states is the number of unique parity packet masks encountered. The saved summary \path|results/experiments/order_668_hypergraph_ca/summary.json| reports \texttt{unique\_state\_count = 512}. Since the number of unique states cannot exceed the number of subset masks and both are $512$, every subset mask induces a distinct parity state. Therefore the retained graph contains exactly $512$ states.
\end{proof}

\subsection{Why the lattice-gas current is nearest-neighbor}

Theorem~\ref{thm:continuity-law} defines the current by cumulative summation. This automatically makes $J(k)$ a quantity living on the edge between lags $k$ and $k+1$. The continuity equation then expresses every lag update $\Delta(k)$ as incoming current minus outgoing current, plus a single boundary-reservoir term at the final lag. No hidden long-range transport term is left over, because the cumulative definition absorbs the entire non-boundary part of the update into the telescoping difference $J(k-1)-J(k)$.
