# De Branges Coefficient Bounds

De Branges' proof of the Bieberbach conjecture establishes that |a_n| <= n for functions in the class S. These sharp coefficient bounds constrain the Taylor series of univalent functions, enabling tighter distortion estimates than those available from the classical Koebe theorem alone. Applied to the Bloch constant, they sharpen lower bound arguments by limiting how fast univalent functions can grow.
