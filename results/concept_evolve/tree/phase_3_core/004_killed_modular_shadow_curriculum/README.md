# Killed: Modular-Shadow Curriculum As A Primary Story

Status: `killed`

This branch is killed as a primary line because modular or finite-ring success is too easy to confuse with integer progress. Green-Ruzsa and Hickman-Wright make the danger explicit: modular structure is an adjacency signal at most, not evidence for the target witness problem over `\mathbb{Z}`. It may survive only as curriculum material if an exact integer lift and verifier gate ever appear.
