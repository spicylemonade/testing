# Concept: optimal_transport_conformal

- Topic Context: try as hard as you can to achieve new non trivial and tighter bounds! Univalent Bloch constant B_u := inf{B_f : f in F, f univalent in D} where D is the unit disk, F is the class of holomorphic functions f:D->C with f'(0)=1, and B_f is the radius of the largest univalent disk in f(D). Current best lower bound: B_u > 0.5708858 (Skinner 2009). Current best upper bound: B_u <= 1 (trivial). The chain B <= B_l <= L <= B_u relates it to Bloch constant B, locally univalent Bloch constant B_l, and Landau constant L.
- Domains: optimal_transport, measure_theory, complex_analysis
