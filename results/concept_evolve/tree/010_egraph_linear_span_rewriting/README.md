# Egraph Linear Span Rewriting

Represent derived certificate expressions and local CA motifs inside an e-graph so equivalent linear combinations and repeated gadget compositions collapse to the same node. This makes R-span search reusable across many generated candidates and exposes algebraic normal forms for witness fragments.

## Context
Terms are generated by basis atoms x e_v, edge-difference constructors, subtraction, and motif constructors. Rewrite rules encode bilinearity, support factoring, coefficient normalization, and local motif identities. An e-graph stores equivalence classes and a cost c(t)=|\mathrm{supp}(t)|+\lambda\,\#\mathrm{motifs}(t) ranks certificate derivations likely to keep r small.

## Why It Is Distinct
The rewrite system is tuned to singleton certificate generation and support size, not to program execution speed.
