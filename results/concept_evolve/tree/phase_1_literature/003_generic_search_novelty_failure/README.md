# Generic-Search Novelty Failure

Status: active novelty-risk card

## Summary

The main way this project fails is by becoming generic automated search with a sophisticated decoder. That happens if the arithmetic content lives in the compiler, if the signal survives label shuffling, or if apparent wins occur only in bounded-slope or modular toy regimes.

## Kill Conditions

- No exact verifier exists, so the lane cannot move beyond design claims.
- The search signal does not collapse under `X`-label shuffling.
- Progress appears only for tiny fixed `X` or modular/finite-alphabet curricula.
- Decoder or repair logic is doing the hard work.

## Why This Is A Real Constraint

AlphaEvolve-style discovery systems, automated-search papers, and generic CA-method papers already cover automation and search machinery in the abstract. The present lane is only novel if verifier-coupled structure, not just search effort, carries the result.
