# Bounded-Slope Prior-Art Pressure

The strongest nearby pressure is not the malformed watchlist. It is the real arithmetic-Kakeya literature, especially Tao's 2025 warning that boundedly many slopes and low rational complexity push the exponent story back toward the wrong regime. Green-Ruzsa, Cowen-Breen et al., and Pohoata-Zakharov add secondary constraints: modular wins do not count, adjacent pattern tasks are not the same target, and generalized reformulations are not original-problem progress.
