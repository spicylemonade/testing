# Generic-Automated-Search Collapse

The main novelty risk is that the project degenerates into generic automated search over a specialized serialization. In that failure mode the apparent contribution is not arithmetic structure, but only the fact that an automated system searched a space of witness strings. AlphaEvolve and later automated-discovery system papers are the relevant comparison class for this risk, not the malformed watchlist.

Kill criteria attached to this card:
- The decoder or compiler performs most of the mathematical work.
- The CA emits heuristic proposals that need repair.
- Any apparent gain vanishes under exact integer verification, label shuffling, or out-of-distribution grids.

Dependency:
- The exact verifier gate must be opened before this risk can be empirically cleared.
