# Extremal Slit Domains

Slit domains -- disks with radial or arc-shaped slits removed -- arise naturally as candidates for extremal configurations in the univalent Bloch constant problem. Carroll and Ortega-Cerda showed that harmonically symmetric 4-fold slit domains yield the best known upper bound B_u <= 0.6564. Understanding which slit configurations minimize inradius is central to tightening upper bounds.
