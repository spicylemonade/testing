# 010 — Compression-Guided Search

## Concept

Not all long Collatz trajectories are created equal. Some are long because they wander chaotically; others are long because they follow structured, repetitive patterns before eventually descending to 1. Compression-guided search uses algorithmic information theory to distinguish these cases: trajectories that are long relative to their Lempel-Ziv complexity are "algorithmically deep" in Bennett's sense — they encode significant computation.

The core metric is a logical depth proxy: delta(n) ≈ D(n) - C_LZ(tau) * log(D(n)), where D(n) is the stopping delay, tau is the encoded trajectory, and C_LZ is the LZ76 complexity. Numbers with high delta have trajectories that are simultaneously long and compressible — they contain repeated motifs, near-cycles, and structured cascades rather than random walks.

These algorithmically deep numbers are prime candidates for delay records and structural anomalies, since their trajectories are generated by nontrivial computational processes within the Collatz dynamics.

## Cross-Domain Connections

- **Algorithmic information theory / Bennett's logical depth**: Logical depth measures the computational content of a string — not its randomness, but the amount of useful work needed to produce it. Deep Collatz trajectories are analogous to deep strings: simple to describe but slow to compute.
- **DNA sequence complexity**: In genomics, LZ-complexity distinguishes functional DNA (structured, moderately compressible) from junk DNA (random, incompressible) and tandem repeats (highly compressible). Collatz trajectories admit the same trichotomy.
- **Compression distance in phylogenetics**: The normalized compression distance (NCD) clusters biological sequences by shared algorithmic content. Applied to Collatz trajectories, NCD could reveal families of numbers whose dynamics share hidden structure.
- **Data compression as inference**: The minimum description length (MDL) principle uses compression as a proxy for understanding. Compressible trajectories are "understood" trajectories — they admit short explanations.

## Implementation Backlog

1. **Trajectory encoding** — Encode each Collatz trajectory as a binary string (e.g., 0 for even step, 1 for odd step) for all n up to 10^7. Store encoded trajectories efficiently.
2. **LZ76 complexity computation** — Implement the Lempel-Ziv 1976 factorization algorithm to compute C_LZ for each encoded trajectory. Benchmark against standard compression libraries.
3. **Depth ranking** — Compute the delay/LZ-complexity ratio for all n. Identify the top 0.1% by this metric. Analyze whether high-depth numbers cluster in specific residue classes or share binary prefix patterns.
4. **Compression distance clustering** — Compute pairwise NCD between trajectories of top-ranked numbers. Apply hierarchical clustering to identify structural families.
5. **Guided candidate generation** — Use patterns discovered in high-depth numbers (common binary motifs, residue class membership) to generate new candidates beyond the enumeration bound.
