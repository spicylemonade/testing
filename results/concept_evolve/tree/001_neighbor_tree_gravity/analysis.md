# Analysis

This branch is deferred, not because the idea is impossible, but because the evidence says it would weaken the paper.

- The smooth-control and small-N benchmarks already show that the direct-sum audited kernel is accurate enough for the intended claim.
- The novelty report and Phase 3 decision log both show that neighbor-tree acceleration would push the project toward a crowded performance narrative instead of the promoted trust-spine contribution.

Result: defer the branch and keep it out of the headline contribution.
