# Skinner's Method Refinement

Skinner (2009) obtained the best known lower bound B_u > 0.5708858 via an iterative scheme that progressively improves a function C(|z|) bounding |f(z)| from below for all univalent f. Refinement focuses on identifying which distortion inequalities in the iteration introduce the most slack and sharpening them using de Branges coefficient bounds or numerical optimization.
