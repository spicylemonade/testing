Transferable lesson: generalized-polynomial structure is the serious exception lane if irrational positives survive, but it is safer as an obstruction or narrow-backup language than as the first theorem target.

3. `Beatty Sequences for a Quadratic Irrational: Decidability and Applications` (2024)

Transferable lesson: generalized/complementary Beatty constructions are a selector bank, not a novelty-safe solution claim for exact value recurrences.

## Angles to avoid

- Repackaging the rational arithmetic-progression baseline as a new theorem.
- Turning the project into a quadratic-Ostrowski classification theorem that merely restates Schaeffer-Shallit-Zorcic.
- Sliding from linearly recurrent words or central sets to arithmetic value recurrences.
- Promoting a broad generalized-polynomial classification before the modular screen leaves real irrational survivors.

## Recommendation

The delegated novelty screen agrees with the director brief: the safest main route is still the modular-shadow / p-adic semilinearity barrier. Use the quadratic and generalized-polynomial papers as comparison branches and exception generators, but let the central theorem language be an obstruction statement for fixed selector families, not another symbolic-dynamics classification.
