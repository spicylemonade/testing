# Director Brief

## Decision

- Champion: `H4_typed_residue_interfaces`
- Backup: `H5_affine_core_nonlinear_shell`
- Reserve only: `H6_phase_coded_defect_transport`

## Hard Blocker

The repo does not support the headline "solve arithmetic Kakeya using cellular automata." There is still no CA-produced legal exact certificate at the live `<= 1.675` bar, `H1_macrocell_substitution` is dead by an exact one-seed obstruction, `H2_target_direction_abelian` is a local null, `H3_slope_bloom` was never activated, and the only exact survivors are fragile direct corridor controls around score `2.0`.

The benchmark layer is also still incomplete. The missing true matched `2 x 8` same-palette direct control, plus the absent low-height asymmetric `X`, bounded-slope, and slowly growing `X` baselines, mean that even the current negative story must stay benchmark-disciplined rather than promotional.

## Why The Champion Leads

`H4_typed_residue_interfaces` is the only route the gap map still treats as a live positive lane rather than a rebranding trap. Its claim is narrow and testable: a finite typed residue interface should be sufficient for exact level-to-level composition under one unchanged extractor, on low-height asymmetric `X`, with matched no-CA controls.

This is also the fastest honest positive route to kill. One frozen interface alphabet, one exact extractor, and one matched baseline matrix are enough to decide whether the interface carries real arithmetic content or whether the apparent signal is just boundary programming or hidden repair.

## Why The Backup Survives

`H5_affine_core_nonlinear_shell` is the best fallback because it attacks the cleanest hidden failure mode: diffuse bulk nonlinearity or solver glue doing the real work. It is not the champion because by itself it does not supply the positive lane; it is a gatekeeper that can either sanitize the champion route or kill CA-flavored optimism quickly.

`H6_phase_coded_defect_transport` stays reserve-only. It is a reasonable fixed-`X` seed-economics hedge, but it sits much closer to the local-decoder, chip-firing, and bounded-slope overlap traps, so it should not move forward unless the top two routes are cleanly screened first.

## Exact Next Experiment For The Researcher

Do not reopen broad CA search. Instead, run one narrow pre-registered test:

1. Freeze one low-height asymmetric `X` family, one typed residue interface alphabet, one exact extractor to legal `(X; d_i; f_i; T; R)`, one symmetry quotient, and one matched baseline matrix.
2. Include in that matrix the true matched `2 x 8` same-palette direct control and the missing non-CA baselines: low-height asymmetric `X`, bounded-slope, and slowly growing `X`.
3. Enumerate exact level-1 residue summaries, then require the same interface table and any admissible nonlinear gate library to compose level-2 with no new symbols and no repair pass.
4. Compare only exact extracted score or hit rate against matched direct no-CA search on the same geometry, palette, and budget.

## Kill And Pivot Rules

- Kill `H4_typed_residue_interfaces` immediately if level-2 needs new interface symbols, if exact extraction needs bespoke repair, if the trace language is tiny or periodic, or if matched direct grammar search recovers the same family.
- Activate `H5_affine_core_nonlinear_shell` only if the failure mode looks like hidden nonlinear or solver-glue leakage rather than simple interface insufficiency.
- Keep `H6_phase_coded_defect_transport` dormant unless fixed-`X` seed economics is still the only untested lever after the first two gates.

If these gates cannot be cleared, the honest outcome remains a negative benchmark-and-falsification workflow, not a CA solution claim.
