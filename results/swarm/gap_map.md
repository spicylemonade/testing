- `H1` and `H2` are closed. This map ranks only reserve directions that are materially different from the retired flat local CA loops.

## Ranked Gaps

### 1. Canonical-path pushdown automaton for the exact `167/80` obstruction

- Type: under-explored setting
- Why it is genuinely under-served:
  - it is the champion reserve branch after `H1/H2` failed;
  - it changes the information channel from flat local moves to canonical-orbit words with deferred multiscale debt;
  - it stays pinned to the exact obstruction behind order `668`.
- What is still missing:
  - an executed transition system on canonical path or run-length words;
  - explicit stack semantics for autocorrelation debt, parity debt, and symmetry obligations;
  - a solved same-template positive control in that representation.
- Primary failure mode:
  - the apparent gain comes only from canonicalization, compression, or static pruning, so the branch collapses into branch-and-bound or SAT+CAS packaging.
- Minimum go/no-go test:
  - compare against a non-automaton prefix search on the same tokenization and with the same exact-completion oracle budget;
  - require zero false negatives on known smaller same-template witnesses plus better frontier reduction or certificate rate before any `167/80` scale-up.
- Priority: highest. This is the cleanest literal `cellar` interpretation that remains materially different from the retired branches.

### 2. Proof-carrying exact-feedback motifs on top of the pushdown frontier

- Type: unsolved gap
- Why it is genuinely under-served:
  - it is the only promoted secondary bridge that adds reusable proof objects instead of another move scheduler;
  - it could turn failed completions into short forbidden motifs or transition guards rather than repeating dead ends.
- What is still missing:
  - a loop that converts exact-completion failures into local motifs or stack-transition vetoes;
  - evidence that learned feedback remains local and reusable across starts of the same template;
  - a static pushdown baseline under the same oracle budget.
- Primary failure mode:
  - unsat feedback stays global, nonlocal, or one-off, so the branch reduces to ordinary SAT+CAS with extra plumbing.
- Minimum go/no-go test:
  - on solved same-template controls, show fewer exact-solver calls and unchanged witness retention than a static pushdown filter with the same completion oracle and the same canonical representation.
- Priority: high. It is the strongest secondary reopen because it adds a new information channel rather than a new label.

### 3. Liability-field search on the exact `167/80` target (`convolution_slice_ca`)

- Type: under-explored setting
- Why it is genuinely under-served:
  - it is the cleanest non-pushdown representation change on the H1 side;
  - it localizes the cyclic obstruction into auditable liabilities instead of raw support bits.
- What is still missing:
  - a same-representation non-CA comparator on the liability field;
  - at least one solved same-template positive control in the liability representation;
  - evidence that liability bookkeeping changes reachability rather than only the score display.
- Primary failure mode:
  - it is just `H1` with prettier state variables, so surrogate-liability improvements do not move exact-hit, closest-target, or orbit-coverage metrics.
- Minimum go/no-go test:
  - benchmark liability-driven CA against non-CA search using the identical liability tables, same oracle, same budget, and the same `4 x 79` and exact `167/80` targets;
  - retire it immediately if the gain is representation leakage rather than a stateful mechanism.
- Priority: high, but below the pushdown line because the collapse risk is still one step away from the failed `H1` family.

### 4. Seed-side hierarchical memory on the published `64`-modular `668` seed

- Type: under-explored setting
- Why it is genuinely under-served:
  - the flat defect-transport `H2` branch is retired, but a seed-side reopen is still logically possible if it adds hierarchy or multiscale memory rather than another local move schedule;
  - the published seed remains the strongest exact near-solution in the repo.
- What is still missing:
  - a coarse-to-fine defect representation or debt pyramid;
  - a discriminative injected-defect control ladder that is harder than the retired `n = 9` toy ladder;
  - more than one real degraded seed or a principled degraded-seed panel.
- Primary failure mode:
  - the branch is only `H2` with hierarchy branding, so any gains vanish once the same start state, neighborhood, accepted-move cap, and verifier are enforced on the real seed.
- Minimum go/no-go test:
  - require same-start fairness against flat greedy and flat CA baselines;
  - require ablation showing the coarse levels matter;
  - require plateau-crossing gains on injected-defect controls that predict improvement on at least one real degraded `668` seed.
- Priority: medium-high. It is the only seed-side reopen worth keeping, but only if it proves more than wrapper novelty.

### 5. Admission discipline gap: reachability screens plus same-template positive controls

- Type: benchmark gap and failure mode
- Why it is genuinely under-served:
  - the reserve packet itself says poor coverage and weak control ladders should not receive new compute;
  - the repo still lacks a locked solved same-template positive control for reserve representations under the same budget rules.
- What is still missing:
  - bounded-time reachability screens for proposed rule families;
  - a canonical positive-control ladder in each new representation;
  - equivalence-aware accounting before any new `668`-scale run.
- Primary failure mode:
  - a branch looks active on toy starts or random prefixes while its reachable set misses the witness family entirely, so compute is spent on a dead search region.
- Minimum go/no-go test:
  - before promotion, require witness retention on smaller same-template controls, a reachability lower bound or rejection screen for the proposed rule family, and a same-representation baseline sheet.
- Priority: medium-high. This is not the solver, but it is the gate that prevents another expensive rerun of an unreachable or non-discriminative branch.

## Why These Five And Not The Popular Branches

- Do not reopen raw support-space CA, density-classifier variants, or flat defect transport. The matched-control packet already retired them.
- Do not prioritize annealing, Ising, or quantum-style wrappers. The novelty packet already treats them as crowded comparator families, not under-served space.
- Do not treat phrase-driven reservoir or branding-heavy `cellar` variants as top gaps. The reserve audit already judged them too weakly tied to the exact obstruction.

## Priority Order

1. canonical-path pushdown with deferred debt
2. proof-carrying exact-feedback motifs
3. liability-field / convolution-slice search
4. seed-side hierarchical memory on the `64`-modular seed
5. admission discipline: reachability plus same-template controls

## Bottom Line

The genuine negative space is no longer "try more cellular automata on Hadamard 668." It is:

- a literal `cellar` reopen as a pushdown-style frontier over the exact `167/80` obstruction;
- a proof-carrying extension that learns reusable local vetoes from exact failures;
- a representation-matched liability search if and only if it proves more than relabeling;
- a seed-side hierarchy only if it breaks the fairness-tied `H2` plateau;
- and strict reachability/control gates before any new `668` run.
