# Tool Plan

- Date: 2026-03-18
- Budget posture: synthesize the existing specialist packet; do not reopen wide literature search, solver construction, or large `167` / `668` runs until the control gates below pass
- Champion route: `autocorrelation_debt_pushdown`
- Backup route: `sat_user_propagator_ca`
- Reserve-only route: `convolution_slice_ca`

## Global Routing Rules

- Zero budget for retired `H1` raw-support CA, retired `H2` flat defect transport, annealing or quantum wrappers, and phrase-only `cellar` branding.
- Every promoted branch must use the same representation for the proposal method and the non-CA comparator.
- Every promoted branch must clear one solved same-template positive control before any `167/80` or `668` scale-up.
- Required endpoints are exact witness retention, exact completability, verified modulus lift, or lower exact-oracle burden at unchanged witness retention. Soft metrics alone do not count.

## Orchestrator

- Route only one active branch at a time: champion first, backup only if champion survives its static-baseline gate, reserve branch only if both fail for representation-specific reasons.
- Inputs:
  - `results/swarm/hypotheses.json`
  - `results/swarm/director_brief.md`
  - `results/swarm/falsifier.md`
  - `results/analysis/phase3_hypothesis_selection.md`
- Budget envelope:
  - small coordination budget
  - no broad web search unless a blocker is specifically terminology or citation ambiguity
  - no compute escalation until comparator design and positive-control validity are signed off

## Researcher

- Route to `autocorrelation_debt_pushdown` first.
- Allowed work:
  - formalize canonical path or run-length representation
  - define deferred-debt state variables
  - prepare one solved same-template positive control
  - draft the matched non-automaton comparator contract
- Backup work on `sat_user_propagator_ca` is conditional on the champion surviving.
- `convolution_slice_ca` is reserve-only and should not receive build budget unless the cellar branches fail for prefix-specific reasons.
- Budget envelope:
  - highest among the three roles that touch method design, but limited to control extraction and comparator setup
  - no large search sweeps
  - no new solver or exploration branch unless the orchestrator reauthorizes after a pass on the control packet

## Falsifier

- Own the first pass on every reopen candidate before the researcher gets scale-up budget.
- Required checks:
  - same-representation comparator exists
  - solved same-template positive control survives
  - no hidden seed privilege, canonicalization privilege, or SAT+CAS packaging advantage
  - exact endpoints are defined before runtime spend
- Budget envelope:
  - early and small, but mandatory
  - enough to reject a branch before any broad run
  - priority order: champion, then backup, then reserve

## Writer

- Write only after the falsifier and benchmark auditor sign off on the control packet.
- Framing rules:
  - describe the work as a reserve reopen around a new information channel
  - do not claim `cellular automata for Hadamard search is untried`
  - do not claim progress on order `668` unless exact endpoints move under matched controls
- Budget envelope:
  - minimal
  - use existing repo evidence first
  - no literature-expansion work beyond clarifying load-bearing claims

## Reviewer

- Review against the repo's kill rules, not against stylistic novelty.
- Required checklist:
  - materially new state channel relative to retired `H1/H2`
  - matched same-representation comparator
  - solved same-template positive control
  - exact or verifier-backed endpoints
  - no collapse into SAT+CAS packaging or family-parameter restatement
- Budget envelope:
  - small
  - concentrated after each control packet, before any promotion to wider spend

## Citation Auditor

- Audit only the load-bearing anchors:
  - Constantine and Constantine (2025)
  - Eliahou (2025)
  - SAT+CAS / Williamson exact-search line
  - CA design and bent-function line
  - phrase-level instability of `cellar automata`
- Reject broad novelty language that the watchlist or falsifier memo already forbids.
- Budget envelope:
  - small and narrow
  - no broad bibliography expansion unless a blocker forces it

## Benchmark Auditor

- Enforce the fairness contract:
  - same representation
  - same verifier and oracle budget
  - same equivalence-aware accounting
  - same seed privilege conditions
  - one solved same-template positive control before real-target spend
- Reject toy-ladder, random-baseline, or surrogate-metric arguments as decisive evidence.
- Budget envelope:
  - medium-small
  - front-loaded before any scale-up
  - equal priority with the falsifier for gatekeeping

## Promotion Sequence

1. `autocorrelation_debt_pushdown`
2. `sat_user_propagator_ca` only if the champion survives
3. `convolution_slice_ca` only if both cellar branches fail for prefix-specific reasons and the representation-collision risk is explicitly addressed
