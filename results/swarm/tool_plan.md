# Tool Plan

## Global routing rules

- No wide literature search, proof search, or construction tuning until the definition lock is written down and the missing or blank scout artifacts are repaired.
- Every empirical or symbolic check must be pre-registered. No post-hoc selector fishing, no prefix-fitting evidence, and no switching between symbolic and arithmetic meanings of recurrence.
- The routing is sequential: orchestrator -> researcher -> falsifier -> writer/reviewer/citation auditor/benchmark auditor. Backup routing is only activated if the champion leaves a clean irrational survivor class.

## Role routing and budget envelopes

- Orchestrator
  - Route: read existing scout outputs, maintain the active hypothesis list, freeze the definition lock, and decide whether the workflow stays on the champion or escalates to the backup.
  - Budget envelope: 1 synthesis pass, 0 new experiments, 0 wide searches, 1 blocker memo if an input artifact is missing.

- Researcher
  - Route: run exactly one pre-registered discriminator experiment for the champion hypothesis.
  - Allowed tool posture: fixed slope panel, fixed selector families, fixed recurrence orders, fixed modulus panel.
  - Budget envelope: 1 run over the panel in the brief, `d <= 4`, 4 selector families, 5 primes plus 1 prime-square check for survivors, 0 untargeted parameter expansion.
  - Escalation rule: only if an irrational survivor remains after the champion screen, route that survivor to the backup Pisot test using the same frozen constructions.

- Falsifier
  - Route: attack the champion with the controls named in `results/swarm/falsifier.md`: rational-triviality, sparse-subsequence leakage, prefix fitting, word/value confusion, and set/sequence confusion.
  - Allowed tool posture: reuse the same panel as the researcher; vary controls, not definitions.
  - Budget envelope: 1 adversarial replay, 1 stress pass on non-Pisot algebraic and transcendental controls, 0 new selector families.
  - Stop condition: one clean irrational counterexample outside the predicted modular-shadow class or one clear post-selection leak blocks writeup.

- Writer
  - Route: draft only after the champion survives falsification or the backup shows a sharp Pisot-only survivor class.
  - Allowed tool posture: write from locked definitions, fixed benchmark panel, and audited citations only.
  - Budget envelope: 1 theorem-outline memo, 1 limitations section, 0 speculative generalization passes.
  - Mandatory inclusions: rational baseline, selector-class scope, exact meaning of recurrence, and a non-novelty disclaimer if the citation audit is still incomplete.

- Reviewer
  - Route: audit the draft for category errors and overclaiming.
  - Checklist: value recurrence versus symbolic recurrence; sequence claim versus set claim; exact identity versus approximation; rational cases first; selector density or definability stated explicitly.
  - Budget envelope: 1 review round before any outward-facing writeup.

- Citation Auditor
  - Route: replace the lexical false-positive watchlist with a real prior-art map focused on the branches named by the falsifier.
  - Required branches: Beatty sequences and variants; mechanical or Sturmian words; linearly recurrent subshifts and S-adic structure; quadratic-Ostrowski decidability; generalized polynomials and bracket words; Beatty self-matching; Skolem-Mahler-Lech and linear recurrence sequence theory.
  - Budget envelope: at most 10 core papers, at most 2 follow-up searches per branch, stop once `results/literature/prior_art_gap.md` contains actual differentiation evidence.
  - Gate: no novelty claim survives until this role signs off.

- Benchmark Auditor
  - Route: verify that the benchmark matrix can genuinely disprove the active claim.
  - Required controls: rationals, `0 < r < 1` if the domain allows it, quadratic irrationals, higher-degree Pisot, non-Pisot algebraic, Salem, transcendental, and positive-density versus zero-density selector classes; add `floor(n r + beta)` only if the project starts drifting toward an inhomogeneous claim.
  - Budget envelope: 1 benchmark checklist, 0 parameter fishing, 1 failure report if any control is missing.
  - Gate: a missing control blocks the writer.
