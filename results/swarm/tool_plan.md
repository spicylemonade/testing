# Tool Plan

- Date: 2026-03-18
- Mode: synthesis-only handoff
- Interpretation: treat `cellar automata` as `cellular automata`; do not claim novelty from the phrase itself.
- Champion route: `H1` Autocorrelation-Realization CA on the `167`-cycle
- Backup route: `H2` Defect-Transport CA lift from the `64`-modular order-`668` seed
- Governance: no broad literature expansion, no solver construction, and no order-`668` compute until the exact source artifacts and control plan are in place.

## Orchestrator

- Route the next turn through `H1` first and open `H2` only if `H1` fails a matched kill test.
- Use local repo artifacts first; allow narrow source retrieval only when a blocker is an exact missing paper artifact.
- Budget envelope: one kickoff pass, one post-target-reconstruction checkpoint, and one promotion review.
- Stop if the required source artifact cannot be reconstructed exactly or if the active branch cannot be distinguished from a classical family.

## Researcher

- Start with `H1`, not with a full-matrix CA and not with a broad rule sweep.
- Phase 0 budget for `H1`: extract the exact `167/80` target and one solved same-template positive control in machine-usable form.
- Phase 1 budget for `H1`: run one matched-budget CA-vs-direct-search sweep on the same symmetry-reduced support space with reachability logging.
- Phase 2 budget: promote `H2` only if `H1` fails cleanly; then extract the published `64`-modular order-`668` seed and run one solved smaller-instance modulus-lift ladder with same-seed non-CA baselines.
- Stop `H1` if it loses to the matched direct-search baseline or collapses into a classical circulant, Williamson, or Goethals-Seidel reformulation. Stop `H2` if it cannot lift solved controls or cannot improve the published seed under matched neighborhoods.

## Falsifier

- Audit the active branch before any `668` run for novelty collapse, unreachable-state risk, and unfair baseline design.
- Budget envelope: one pre-run fail memo and one post-control kill check.
- Require same-representation fairness for `H1` and same-seed fairness for `H2`.
- Stop the branch if the claimed gain is only lower autocorrelation distance or lower defect energy without an exact hit, a modulus lift, or a clear certificate-level improvement.

## Writer

- Write only after the active branch has an exact artifact, a control ladder, and a pre-registered kill rule.
- Budget envelope: one short methods brief and one results brief; no speculative framing beyond the active branch.
- Keep the claim narrow: CA may help with the exact `167/80` obstruction or, if promoted, the specific `64`-modular repair problem. Do not generalize to Hadamard search as a whole.
- Stop if the evidence packet does not contain matched baselines, exact metrics, and a clear negative-result path.

## Reviewer

- Review the branch at two gates: after artifact extraction and after the first matched control sweep.
- Budget envelope: one gate review per checkpoint.
- Check that the implementation and writeup still match the chosen hypothesis rather than drifting into generic local search or classical structured enumeration.
- Stop if controls, equivalence handling, or exact verifier integration are missing.

## Citation Auditor

- Verify only the load-bearing sources for the active branch and cut any citation padding.
- Budget envelope: up to ten anchor citations in the internal brief unless a blocker forces one more exact source.
- Champion anchors: Constantine and Constantine 2025, matched structured-search baselines, and the closest CA heuristic literature.
- Backup anchors: Eliahou 2025, CA decoder or repair work, and matched Hadamard local-search baselines.
- Stop if a novelty or prior-art claim is supported only by adjacent literature rather than a direct source.

## Benchmark Auditor

- Lock the benchmark sheet before implementation, not after the first promising run.
- Budget envelope: one benchmark sheet for `H1` and one dormant sheet for `H2`.
- `H1` controls must include one solved same-template positive, same-representation direct search, equivalence-aware accounting, and exact target-hit or closest-target metrics rather than random-baseline wins.
- `H2` controls must include same-seed non-CA local search, solved smaller modular-to-exact lifts, equivalence-aware accounting, and exact modulus or certificate metrics.
- Stop if any baseline is colder, weaker, or differently represented than the proposed method.
