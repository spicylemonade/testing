# Literature Baseline Comparison

| branch | literature baseline | project result on the frozen panel | comparison outcome | `sources.bib` keys |
| --- | --- | --- | --- | --- |
| Beatty / Sturmian / automatic | Quadratic Beatty and Sturmian papers prove synchronization or decidability of symbolic or graph relations. | The project adds an exact recurrence screen: AP/FUAP selectors collapse to rationals, four isolated `quadratic_convergent_even` identities certify exactly, and every remaining sparse holdout stays empirical only. | The main contribution shifts from definability to exact recurrence classification under frozen selector scope, while keeping symbolic results in a supporting role. | `schaeffer2024`, `hieronymi2021`, `baranwal2021` |
| Linearly recurrent subshifts / S-adic | Durand's line characterizes symbolic linear recurrence and proper primitive S-adic structure. | Our H1 theorem-backed lane proves irrational exclusion for AP/FUAP selectors and treats symbolic LR only as a category-error warning for numeric claims. | The project does not reprove symbolic LR results; it separates them from the ordered value problem and uses them only as selector heuristics. | `durand2000`, `durand2003`, `durand1998` |
| Generalised polynomials / Pisot-Salem | Byszewski-Konieczny show that some Pisot or Salem recurrence-value sets are generalized-polynomial definable. | In the frozen constructions, the only exact-certified irrational cases are the four quadratic-convergent identities; plastic, Salem, and transcendental controls produce no exact certificate, and the strongest nonquadratic anomaly fails by holdout length `80`. | The reverse embedding problem remains unresolved beyond isolated quadratic examples, so no Pisot/Salem boundary claim is made. | `byszewski2023`, `byszewski2016`, `adamczewski2022`, `allouche2018` |
| Skolem-Mahler-Lech / recurrence theory | SML gives arithmetic-progression structure for zeros or orbit intersections of an already-given recurrence. | The project uses that language on the Beatty side: exact certificates, long holdouts, and modular-shadow checks reject candidate recurrences before they are promoted. | The contribution is the ordered-value obstruction theorem plus a conservative screening workflow, not another zero-set theorem. | `bell2005`, `derksen2005` |
| Uniform recurrence / central sets | Central-set papers show rich combinatorial structure from uniformly recurrent words and symbolic recurrence. | The project explicitly refuses to count such symbolic evidence unless it compiles back to an exact recurrence of the ordered value sequence. | This row is a deliberate anti-baseline: it marks the category boundary that protects the novelty claim. | `bucci2013` |
