# Literature Baseline Comparison

| branch | literature baseline | project result on the frozen panel | comparison outcome | `sources.bib` keys |
| --- | --- | --- | --- | --- |
| Beatty / Sturmian / automatic | Quadratic Beatty and Sturmian papers prove synchronization or decidability of symbolic or graph relations. | The project adds an exact recurrence screen: positive-density selectors collapse to rationals, while quadratic zero-density survivors are isolated by exact holdout and modular-shadow filters. | We use the automatic lane as infrastructure, but the main claim shifts from definability to exact recurrence classification. | `schaeffer2024`, `hieronymi2021`, `baranwal2021` |
| Linearly recurrent subshifts / S-adic | Durand's line characterizes symbolic linear recurrence and proper primitive S-adic structure. | Our H1 theorem-backed lane proves irrational exclusion for arithmetic and finite-union selectors and treats symbolic LR only as a category-error warning for numeric claims. | The project does not reprove symbolic LR results; it separates them from the value problem and uses them only as selector heuristics. | `durand2000`, `durand2003`, `durand1998` |
| Generalised polynomials / Pisot-Salem | Byszewski-Konieczny show that some Pisot or Salem recurrence-value sets are generalized-polynomial definable. | In the frozen constructions, quadratic survivors exist, but cubic Pisot plastic and Salem/transcendental controls fail; the concrete suffix-`10` beta-endpoint proxy produces no exact low-order survivor. | The reverse embedding problem is harder than the definability problem and remains negative beyond the quadratic lane in the current evidence. | `byszewski2023`, `byszewski2016`, `adamczewski2022`, `allouche2018` |
| Skolem-Mahler-Lech / recurrence theory | SML gives arithmetic-progression structure for zeros or orbit intersections of an already-given recurrence. | The project moves that language to the front end: modular-shadow and holdout checks reject Beatty candidates before they are promoted to exact recurrences. | The new contribution is a Beatty-side obstruction filter, not another theorem about zero sets of known recurrences. | `bell2005`, `derksen2005` |
| Uniform recurrence / central sets | Central-set papers show rich combinatorial structure from uniformly recurrent words and symbolic recurrence. | The project explicitly refuses to count such symbolic evidence unless it compiles back to an exact recurrence of the ordered value sequence. | This row is a deliberate anti-baseline: it marks the category boundary that protects the novelty claim. | `bucci2013` |
