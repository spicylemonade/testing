# Problem Frame

## Target Question

Let `a_n = T(1,n)`. The target question is whether the first-difference sequence

`a_{n+1} - a_n`

is bounded.

Equivalently, can the greedy product-coverage process create arbitrarily long fully covered frontier intervals immediately below the next new first-row term, or is there a global constant bounding their length?

## Active Hypothesis Ladder

- Primary: `H1_frontier_witness_certificate`
  - Goal: explain long gaps by witness-carrying frontier coverage specific to the endogenous border sets generated by the recurrence.
  - Required evidence: for each skipped integer in each record gap, store a valid border witness, witness multiplicity when cheap, skipped-prime/composite status, and row/column metadata.
- Backup: `H2_prime_support_fixed_point`
  - Goal: test whether prime-support observables explain record gaps better than direct frontier witnesses.
  - Constraint: it only survives if it adds explanatory power on the same corpus used for `H1`.
- De-prioritized: `H3_near_minimal_multiplicative_basis`
  - Reason: it overlaps too directly with multiplication-table and divisor-in-an-interval prior art unless a specifically `T`-driven invariant emerges.

## Stop Conditions

- Stop immediately if the recurrence implementation cannot be validated.
- Stop `H1` if witness logs do not yield either a compact certificate language or a sharp obstruction explaining why such compression fails.
- Promote `H2` only if support observables explain failures that direct frontier witnesses do not.
- Do not widen into generic mex, prime-gap, or multiplication-table narration without targeted prior-art clearance.

## Recurrence-Order Warning

The falsifier memo identifies the main implementation trap:

- `T(1,n+1)` is chosen from the old `n x n` square.
- `T(n+1,1)` is then chosen from the same old `n x n` square, excluding the just-chosen `T(1,n+1)`.
- Only after those two border terms are fixed are the new products `T(m,n+1) = T(m,1) * T(1,n+1)` introduced.

Any generator that lets the new products influence the choice of `T(n+1,1)` is implementing the wrong process.

## Research Posture

The current evidence state is not strong enough to prove boundedness or unboundedness. The right immediate objective is narrower:

- build one validated baseline generator;
- reproduce and extend the record-gap evidence past the stale small-horizon notes;
- assemble a witness-carrying corpus that can either support `H1`, promote `H2`, or kill both lines cleanly.
