# H1 Design Brief

Prepared for rubric `item_011`.

## Branch identity

- Name: `Autocorrelation-Realization CA on the 167-cycle`
- Status: implemented, tested, and retired after the matched-budget baseline review in [`results/analysis/phase2_baseline_review.md`](/home/archivara/work/repo/results/analysis/phase2_baseline_review.md)
- Exact target: the unresolved `167/80` cyclic obstruction stored in [`results/artifacts/target_167_weight_80.json`](/home/archivara/work/repo/results/artifacts/target_167_weight_80.json)

## State and boundary conditions

- Cell state: one binary support bit per residue class of the cycle.
- Global constraints:
  - fixed length `167`,
  - fixed Hamming weight `80`,
  - support interpreted only through the exact target periodic autocorrelation half-vector.
- Boundary condition: periodic. The search lives on the cycle graph `Z/167Z`.
- Canonical orbit representative: dihedral orbit reduction via `cyclic_canonical_binary`, recorded by the verifier as `canonical_orbit`.

## Neighborhood and update rule

- Local neighborhood:
  - edges are generated by the odd-cycle three-matching schedule in [`hadamard668/h1.py`](/home/archivara/work/repo/hadamard668/h1.py),
  - each phase exposes only disjoint adjacent transpositions,
  - swaps are admissible only on `01` or `10` edges, so weight is conserved exactly.
- Active CA rule:
  - score each admissible swap by exact change in the target-distance objective,
  - select local-dominant improving swaps inside a short window,
  - fire several non-conflicting swaps in parallel, capped by `phase_move_cap = 4`.
- Matched comparator:
  - `direct_greedy` sees the same edges, same step budget, and same cap per phase,
  - it simply takes the best improving swaps on that same phase instead of the local-dominance CA rule.

## Seed families

- `perturbed_solution`: local perturbations of the solved `4 x 79` control support.
- `random_weight`: uniform random supports of the right weight.
- `modular_projection`: deterministic projections induced by the published order-668 modular seed.

## Invariants and verifier

- Conserved quantities:
  - length,
  - support weight,
  - representation class as a support-space search rather than a family-parameter search.
- Verifier state from [`hadamard668/verifiers.py`](/home/archivara/work/repo/hadamard668/verifiers.py):
  - `periodic_autocorrelation_half`,
  - `autocorrelation_debt`,
  - `closest_target_distance`,
  - `max_defect_magnitude`,
  - `exact_hit`,
  - PSD diagnostic.
- Optimization order:
  - exact hit first,
  - otherwise minimize `closest_target_distance`,
  - break ties by `max_defect_magnitude`.

## Orbit slicing and reachability logging

- Each visited state is collapsed through the same dihedral canonical representative.
- Run records log:
  - `visited_states`,
  - `unique_orbits`,
  - `orbit_collapse_ratio`,
  - `accepted_moves`,
  - periodic snapshots,
  - best and final verifier states.
- This keeps the branch framed as a reachability experiment on the exact obstruction, not as a family restatement.

## Why this is not a circulant / Williamson restatement

- The search variable is the raw support indicator on the exact `167`-cycle.
- No Williamson, Goethals-Seidel, or other family parameters are exposed to the update rule.
- The only objective is agreement with the exact target autocorrelation vector from the current cyclic obstruction.

## Decision

- The design was specific enough to test the intended novelty claim.
- The claim failed empirically because the matched `direct_greedy` baseline beat `parallel_gain_ca` on both the solved control and the unresolved target.
