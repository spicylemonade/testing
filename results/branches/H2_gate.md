# H2 Gate

`H2_lag_space_ca_167` opens only behind a locality-failure gate. It is not a fallback for weak tuning, weak budgets, or missing control runs.

## Activation Rule

Activate H2 only if the evidence says H1 fails for principled locality reasons, for example:

- the current single-packet q/s basis is frozen on the canonical seed even after matched control runs;
- raw q/s packet neighborhoods are shown to be fake-local in effect, so H1 cannot stay honest as a CA in that representation;
- H1 oscillates between diffusion and paralysis on the frontier seed because the true local object appears to be the lag-defect field rather than the packet ring.

Do **not** activate H2 if H1 only needs:

- routine parameter tuning,
- cleaner accounting,
- better restart policy,
- or basic implementation fixes.

## Why H2 Exists

H2 is the backup only because it moves the CA state closer to the actual defect object: lag residues over the prime core `167`.

That is defensible only if the branch remains a locality experiment in lag space rather than a disguised return to a known structured-family search.

## Family-Leakage Audit

Before spending real budget on H2, reject or relabel the branch if it silently collapses into any of the following:

1. `Williamson`
   - H2 must not hard-code four circulant/amicable sequence relations that reduce the search to Williamson-type equations.

2. `Turyn`
   - H2 must not introduce supplementary-sequence identities or Turyn multiplication structure as hidden invariants while still claiming a new CA branch.

3. `Goethals-Seidel`
   - The repo already uses a fixed Goethals-Seidel lift from q/s into `(A, B, C, D)`.
   - H2 is acceptable only as a new lag-space search dynamic on top of that shared lift, not if it merely re-labels a standard Goethals-Seidel family search.

4. `cocyclic`
   - H2 must not quietly re-enter cocyclic / transposed-Ito / `D_{4t}` style constraints and then present the result as CA locality rather than as optimizer-over-known-family.

5. `block-circulant`
   - H2 must not impose block-circulant or quasi-circulant templates beyond the already fixed compact q/s representation.

If any of those leakages occurs, relabel the work as optimizer-over-known-family and do not open H2 as a distinct research branch.

## Minimum Evidence Required To Open H2

H2 may open only after all of the following are true:

- H1 has completed its first matched control runs and the first canonical frontier kill test.
- The failure is attributed to locality or actuator-basis mismatch rather than to unfair accounting or weak engineering.
- The H1 evidence is already summarized in the verification pack strongly enough that a pivot can be defended.

## First H2 Budget

If H2 opens at all:

- use one lag-space representation only;
- keep one matched non-CA lag-space control;
- keep the budget narrower than H1 until H2 shows it is not just structure leakage.
