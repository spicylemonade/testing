# Spectral Analysis of Collatz Predecessor Graph

## Key Findings

### N = 3,000
- Spectral gap: 0.000161
- KS distance to GOE: 0.164851603976897
- KS distance to Poisson: 0.10125040093573501
- Closer to: **Poisson**

### N = 10,000
- Spectral gap: 0.000006
- KS distance to GOE: None
- KS distance to Poisson: None
- Closer to: **Poisson**

### Spectral Gap Scaling
λ₂ ∝ N^-2.77

## Novelty Assessment
This is the first computation of eigenvalue spacing statistics for the
Collatz predecessor graph. No prior work compares Collatz graph spectra
to random matrix ensembles (GOE/GUE/Poisson).
