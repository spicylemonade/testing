# Transfer Matrix Lyapunov Exponent Analysis

## Parameters
- N = 100000

## Key Findings

- Mean Lyapunov exponent: **0.000123** (theoretical: 0.202733)
- Standard deviation: 0.000368
- KS test vs Normal: stat=0.3690, p=0.00e+00
- Correlation with 2-adic valuation: 0.0357
- Correlation with popcount: -0.0497
- Number of high outliers (z>4): 7

## Interpretation

The Lyapunov exponent distribution **deviates significantly from Normal**.
This non-Gaussianity indicates the transfer matrix products are NOT
well-described by a simple random matrix model.
